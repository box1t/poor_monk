Стек - это структура с единственной читающей-записывающей головкой, последовательным доступом и неразрушающей записью. Чтение из стека, как и у очереди, разрушающее (происходит удаление!) 
Обработать данные внутри стека нельзя вообще. их надо вынимать.
Пришедший первым уходит последним - определяющий принцип такой структуры данных.

Если стек пустой, значит в нём нет верхнего элемента. Это рекурсивное определение стека.

# Применение стека:

***В жизни***:
- Тарелки 
- Бюрократ складывает бумаги на стол.
(По-справедливости первые бумаги должны были работать сразу.) 

- Уровни протоколов TCP/IP также принято складывать в стек. 
- Пополнение сырков на охлаждаемый прилавок в супермаркете.

***В задачах информатики***:
- Выполнение рекурсивной процедуры организуется с помощью стека;
- Стеки везде! В рекурсии стек неявный.
- В стеке удобно отводить память под локальные переменные единиц блочной структуры;
- Синтаксический анализ текста использует стеки; 
- Вложенная структура процедур такова, что омонимичные переменные образуют стек.

# Функциональная спецификация

Стек - множество переменного числа данных, на котором выполняются следующие операции:

- пополнение стека новыми данными;
- проверка, определяющая, пуст ли стек;
- просмотр вернего (самого нового) элемента, если он существует;
- уничтожение последнего добавленного, но ещё не уничтоженного элемента, если он есть.

Функциональные спецификации стека и очереди отличаются последними свойствами (LIFO и инверсия):

1. Созданный стек пуст.
2. Занесение элемента в стек делает его не пустым.
3. Занесённый элемент в стек становится его верхушкой
4. После взятия элемента с верхушки с возвращением его в стек получаем исходный стек

Различия между ними также провляются в их разноголовочности:

- стек - одноголовочная *структура*;
- очередь - двухголовочная.


Стек сам по себе медленный, нам нужна его верхушка, которую можем использовать с космической скоростью. 
У стека неподвижное дно, а верхушка плавающая.

Стек, как и очередь - рекурсивная структура данных.
Стек есть конкатенация верхушки и тела стека, которое в свою очередь является стеком. 
Частью стека является тоже стек.
В отличие от очередей, стеки имеют аппаратную поддержку во всех современных процессорах.

Функциональная спецификация стека = рекомендация к его тестированию.

```c
Логическое описание / функциональная спецификация стека:
struct Item { // тип "элемент стека"
	T data;
	struct Item* prev;
}
typedef struct { // определение в двух переменных:
	struct Item* top; // указатель на вершину стека
	int size; // переменная-глубина стека
} stack;

void Create(stack* s); // 1
bool Empty(stack* s); // 2
bool Size(stack* s); // 3
bool Push(stack* s, T t); // 4
bool Pop(stack* s); // 5
T Top(stack* s); // 6
void Destroy(stack* s); // 7

```

# Логическое описание

Верхний элемент стека играет особую роль: его можно рассмотреть или уничтожить.
Оставшаяся часть - тело стека. Если снять со стека верхушку, то тело превращается в стек.

Стек есть конкатенация верхушки и тела стека, которое в свою очередь является стеком. 
Частью стека является тоже стек.

Для эффективной вычислимости необходим терминатор, ограничивающий глубину рекурсии описания, роль которого играет пустой стек.



### Понятие обхода дерева

При анализе деревьев применяются разные способы ***пересмотра*** или ***перебора*** узлов дерева.
Такой просмотр называется ***обходом*** дерева.

Особенность состоит в просмотре всех без исключения узлов дерева в некотором порядке, причем каждый узел обрабатывается ровно один раз.

Обход представляет собой линейно упорядоченное рассмотрение всех его вершин, от предыдущего элемента к следующему.

==пустота структуры - хороший принцип её завершения==


### Обходы двоичных деревьев (3 обхода)

 
Для бинарного дерева определены три способа обхода: прямой, обратный и концевой.
Эти способ определяются рекурсивно.

Действия при обходах:

1. При прямом обходе (КЛП) (preorder-ный обход):
- если дерево пусто, то конец обхода
- берется корень
- выполняется обход левого поддерево
- выполняется обход правого поддерева


==преордерный означает, что корень обходится прежде==
==обход корня - просмотр, взятие его значения==

==на экзамене обязательно надо написать один из кодов==

2. При обратном обходе (ЛКП, inorder):
- если дерево пусто, то конец обхода
- выполняется обход левого поддерева
- берется корень
- выполняется обход правого поддерева

==inorder- корень между поддеревьями. входим в корень и не смотрим в него. идем влево, затем в корень, затем вправо.==


3. При концевом обходе (ЛПК): 
- если дерево пусто, то конец обхода
- выполняется обход левого поддерева
- выполняется обход правого поддерева
- берется корень

Составим рекурсивную процедуру обхода двоичного дерева.
Ссылка на текущий корень дерева передаётся по значению, и заносится при рекурсивном исполнении во временной стек экземпляров локальной переменной.
При обходе изменение значений этой переменной не производится.

Нерекурсивной обход осуществим при помощи рекурсивной структуры данных стека.

class Solution {
public:
    int helper(TreeNode* root, vector<int>& ans) {
        if (root == nullptr) {
            return;
        }
        helper(root->left, ans);
        ans.push_back(root->val);
        helper(root->right, ans);
    }
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> ans;
        helper(root, ans);
        return ans;
    }
};

struct Node {
	int data;
	Node* left;
	Node* right;
};

void Preorder(Node* root) {
	if(root == nullptr) {
		return;
	}
	std::cout << root->data;
	Preorder(root->left);
	Preorder(root->right);
}

void Inorder(Node* root) {
	if(root == nullptr) {
		return;
	}
	Inorder(root->left);
	std::cout << root->data;	
	Inorder(root->right);
}

void Postorder(Node* root) {
	if(root == nullptr) {
		return;
	}
	Postorder(root->left);
	Postorder(root->right);
	std::cout << root->data;
}

### Обходы дерева общего вида (2 обхода)

Деревья общего вида имеют более сложную структуру.
В силу произвольности числа разветвлений каждого узла для их обхода 
требуются цикл или рекурсия.

Посмотрим очередь сыновей. 
Это можно сделать обходом в ширину или в глубину.

1. ***При поиске в глубину***:
- Если дерево пусто, то конец обхода
- Берётся корень
- Выполняется поиск в глубину для поддерева старшего сына
- Выполняется поиск в глубину для следующего брата

2. ***При поиске в ширину***:
- Поместить в пустую очередь корень дерева
- Если очередь узлов пуста, то конец обхода
- Извлечь первый элемент из очереди узлов и поместить в её конец всех его сыновей по старшинству.
- Повторить поиск, начиная с проверки очереди на пустоту .

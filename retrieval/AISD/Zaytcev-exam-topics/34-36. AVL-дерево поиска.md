Каждое включение элемента приводит к разбалансировке дерева поиска, а значит, и к ухудшению времени доступа.
Для этого учёные Адельсон-Вельский и Ландис предложили дерево, высоты поддеревьев каждой из вершин которого отличаются не более, чем на единицу.

Даже в худшем случае в AVL-дереве за логарифм выполняются операции:
- поиска вершины с данным ключом
- включения вершины
- исключения вершины

По теореме AVL сбалансированное дерево поиска не превышает по высоте идеально сбалансированное дерево более чем на 45%.
Минимум достигается при идеальной балансировке, т.е. при n= 2^k - 1.


# Вставка в AVL-дерево


Если дерево состоит из корня t и L R поддеревьев, то либо оно идеально сбалансировано и вставка вершины углубит одно из поддеревьев на единицу. Либо вставляемая вершина попадёт в более низкое поддерево и улучшит сбалансированность.

При попадании узла в более высокое поддерево, AVL-сбалансированность дерева нарушится и возникнет необходимость балансировки дерева.

Рассмотрим дерево.
![](Pasted%20image%2020230625184219.png)

Вершины с ключами 9 и 11 вставятся без нарушения сбалансированности.

Включение 1, 3, 5, 7 разбалансирует дерево.

С точностью до симметрии существует 2 возможности несбалансированности, возникшей из-за включения (отличие местом возникновения: с края или в середине дерева.)

1. Вставка 1 или 3
2. Вставка 5 или 7

Балансировка подобна манипуляции с нитками кукол-марионеток: дергаем ветки, не перекрещивая пальцы.


Алгоритм включения:
1. Поиск элемента в дереве
2. Вкдючегие новой вершины и определение показателя сбалансированности
3. Отход от поиска с проверкой показателя сбалансированности для каждой вершины, балансируя поддеревья при необходимости.

Алгоритм проверки сбалансированности - дорогое удовольствие, происходит за O(N), где N - число вершин.

Пример на псевдокоде:
```c
1. Задаём структуру вершины дерева
2. void search(int x, ptr* p, int* h)
	2.1 Включение
	2.2 Балансируем правую, если включили правую
	2.3 Балансируем левую, если включили левую 
```

Если ветвь стала длиннее, совершаем поворот по этой же ветви.

# Удаление из AVL-дерева

Процедура следует схеме включения элемента
Удаление терминальной или однодетной вершины - задача в одно действие.
Двудетные вершины обрабатываются как и раньше - заменяются на самую правую вершину левого поддерева.
Исключение любого элемента из сбалансированного дерева оценивается O(logN).

Если ветвь стала короче, совершаем поворот противоположной ветви.

Пример на псевдокоде:
```c
1. void balanceL(ptr* p, int* h) // h: левая ветвь стала короче, её балансируем
	1.1. Балансировка
	1.2. однократный R-R поворот
	1.3. двойной R-L поворот

2. void balanceR(ptr* p, int* h) // h: правая ветвь стала короче, её балансируем
	2.1. Балансировка
	2.2. однократный L-L поворот
	2.3. двойной L-R поворот

3. void delete(int x, ptr* p, int* h) 
	3.1 Вернуть NULL, если нет ключа нет
	3.2 Рекурсивное применение
	3.3 Удаление
	3.4 Балансировка
	3.5 Высвобождение памяти
```

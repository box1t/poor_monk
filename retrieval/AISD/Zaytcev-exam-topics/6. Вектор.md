В 1 семестре мы пользовались статическими массивами.
И хотя их длина известна, а также легко проверить выход за границы, они неудобны в практическом программировании.
Переполнение статического массива ведёт к отказу программы, к тому же массив небезопасен.

В этой ситуации полезны ***динамические массивы***, или ***векторы***.
Они располагаются в куче, и их размер задан произвольно (длина ограничена размером доступной памяти).
==главное в векторе это реаллокация! меняет длину!==

***
# Функциональная спецификация

Вектор - последовательность переменной длины.
Время доступа к элементам постоянно, не зависит от длины вектора.
Вектор с 0 компонент считаем пустым.

Операции сложения и скалярного произведения производятся с векторами разной размерности. Поэтому длина - важная характеристика вектора.

Индекс первого элемента 0, т.к. при выделении памяти возвращается адрес начала этого блока.

Для доступа к компоненте прибавляем к адресу блока размер компоненты, умноженной на индекс. Если индексация не с 0, то дополнительно производят сложение.

Операции над вектором:
- Создать
- Пусто
- Длина
- Загрузить
- Сохранить
- Изменить длину
- Равны
- Уничтожить

==выкинув "создать, уничтожить, изменить длину" получим массив. это те самые операции, не нужные массиву==

# Логическое описание и физическое представление

Два вектора считаются равными тогда и только тогда, когда их длины равны, а также равны соответствующие компоненты.

Сначала опишем сам тип вектор. Он должен включать в себя описатель хранимой последовательности и её длину.


```c
Пример объявления функций:
// #0. Задаём тип вектор.
typedef struct {
	T* data;
	int size;
} Vector;

void Create(Vector* v, int sz); // 1. определяем длину
bool Empty(Vector* v); // 2. проверка на пустоту путем сравнения длины с 0
int Size(Vector* v); // 3. получение длины за постоянное время O(1)
T Load(Vector* v, int t); // 4. чтения и записи компоненты по данному индексу
void Save(Vector* v, int i, T t); // 5. вручную проверяет выход за границу массива
void Resize(Vector* v, int sz); // 6.
bool Equal(Vector* l, Vector* r); // 7.
void Destroy(Vector* v); // 8. удалить вектор и вернуть память ОС (при помощи free)

```




***
В процессе создания вектора определяется его длина:
```c
// #1. Void-функция Create(Vector*v, int sz);
void Create(Vector* v, int sz) {
	v->size = sz;
	v->data = malloc(sizeof(T) * v->size);
}

```

Проверка на пустоту определяется путём сравнения длины с 0.

```c
// #2. bool Empty(Vector* v);
bool Empty(Vector* v) {
	return v->size == 0;
}

bool Empty(Vector* v) {
	return v->size == 0;
}


```


Получение длины вектора выполняется за постоянное время O(1)
```c
// #3. int Size(Vector* v);
int Size(Vector* v) {
	return v->size;
}

```




Определим операции чтения и записи компоненты по данному индексу.

Реализация на Си вручную проверяет выход за границу массива и возбуждает исключение.


```c
// #4. T Load(Vector* v, int i); -- функция "загрузить"
T Load(Vector* v, int t) {
	if((i >= 0) && (i < v->size)) {
		return v->data[i];
	}
}

// #5. void Save(Vector* v, int i, T t); -- функция "сохранить"
void Save(Vector* v, int i, T t) {
	if ((i >= 0) && (i < v->size)) {
		v->data[i] = t;
	}
}

```

```c
// #7. bool Equal(Vector* l, Vector* r);
bool Equal(Vector* l, Vector* r) {
	if(l->size != r->size)
		return false;
	for (int i = 0; i < l->size; i++){
		if(l->data[i] != r->data[i]) {
			return false;
		}
		return true;
	} 
}

```


По окончании работы необходимо удалить вектор и вернуть память ОС.
Для этого в Си необходимо вызвать функцию free.

```c
// #8. void Destroy(Vector* v);

void Destroy(Vector* v) {
	v->size = 0;
	free(v->data);
}
```

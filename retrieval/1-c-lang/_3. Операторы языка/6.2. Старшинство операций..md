
Старшинство операций.

### **Краткий конспект:**

1. **Наивысший приоритет:**
    
    - Операции **именования памяти**:
        - Доступ к членам структуры (`.`).
        - Доступ к элементам массива (`[]`).
        - Вызов функции (`()`).
2. **Приоритет операций:**
    
    - **Одноместные операции** (например, `~`, `!`, унарный `-`) **выше двухместных**.
        
    - **Мультипликативные операции** (`*`, `/`, `%`) имеют **выше приоритет**, чем **аддитивные** (`+`, `-`).
        
    - **Логические операции:**
        
        - **Конъюнкция** (`&&`) имеет выше приоритет, чем **дизъюнкция** (`||`).
    - **Побитовые операции:**
        
        - Приоритет:
            
            ```text
            & > ^ > |
            ```
            
    - **Отношения:**
        
        - Операции сравнения (`<`, `<=`, `>`, `>=`, `==`, `!=`) имеют ниже приоритет, чем арифметические и сдвиги.
    - **Присваивания:**
        
        - Присваивание (`=`) и сокращённые операции присваивания (`+=`, `-=`, `*=`, и т.д.) имеют **низший приоритет**, за исключением **операции запятая** (`,`).

---

### **Примеры для иллюстрации приоритета:**

#### **1 Пример с арифметическими операциями:**

```cpp
int a = 5 + 2 * 3; // a = 5 + (2 * 3) = 5 + 6 = 11
```

#### **2 Пример с побитовыми операциями:**

```cpp
int x = 5 & 3 | 2; // x = (5 & 3) | 2 = 1 | 2 = 3
```

#### **3 Пример с логическими операциями:**

```cpp
bool result = 0 || 1 && 0; // result = 0 || (1 && 0) = 0 || 0 = false
```

#### **4 Пример с операцией сравнения:**

```cpp
bool check = 5 + 2 > 3 * 2; // check = (5 + 2) > (3 * 2) = 7 > 6 = true
```

#### **5 Пример с присваиванием:**

```cpp
int y = (5, 10); // y = 10 (результат выражения "запятая" — последний операнд)
```

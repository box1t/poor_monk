#### **1. Для чего в языке C нужно "условие"?**

Условие (condition) в языке C используется для управления потоком выполнения программы. Оно позволяет выполнять разные участки кода в зависимости от значения логического выражения. Основные цели:

- **Ветвление программы**: выполнение разных блоков кода в зависимости от условий (`if`, `switch`).
- **Циклическое управление**: определение продолжительности выполнения (`while`, `for`, `do-while`).
- **Ограничение выполнения операторов**: например, `?:` (тернарный оператор) выполняет выражение на основе условия.
- **Обеспечение безопасности**: условия помогают предотвращать ошибки, например, защиту от деления на ноль.

---

#### **2. Методы и сигнатуры условий в C**

В языке C существуют несколько способов задать условия:

##### **2.1. Оператор `if`**

```c
if (condition) {
    // Выполняется, если condition истинно (не 0)
}
```

Возможны вариации:

```c
if (condition) {
    // Блок кода 1
} else {
    // Блок кода 2
}
```

```c
if (condition1) {
    // Блок 1
} else if (condition2) {
    // Блок 2
} else {
    // Блок 3
}
```

##### **2.2. Тернарный оператор `?:`**

```c
result = (condition) ? value_if_true : value_if_false;
```

Пример:

```c
int min = (a < b) ? a : b;
```

##### **2.3. Оператор `switch-case`**

Позволяет заменить несколько `if-else` при сравнении с целочисленными константами:

```c
switch (expression) {
    case value1:
        // Действие 1
        break;
    case value2:
        // Действие 2
        break;
    default:
        // Действие по умолчанию
}
```

##### **2.4. Логические операторы (`&&`, `||`, `!`)**

Используются в условиях:

```c
if (a > 0 && b > 0) {
    // Выполнится, если оба числа положительные
}
```

##### **2.5. Условные выражения в циклах**

Используются в `while`, `for`, `do-while`:

```c
while (condition) { ... }
for (init; condition; increment) { ... }
do { ... } while (condition);
```

##### **2.6. `goto` с условием**

Хотя `goto` не рекомендуется, его можно использовать для выхода из вложенных циклов:

```c
if (error) goto errorHandler;
```

#### **3. Связанные термины**

- **Логическое выражение** (Boolean expression): выражение, которое оценивается в `true` или `false` (в C это `1` и `0`).
- **Короткое замыкание (short-circuit evaluation)**: при `&&` и `||` правая часть выражения не вычисляется, если результат уже определён.
- **Фолбэк (fallback)**: блок `else` или `default` в `switch`, выполняющийся, если другие условия не сработали.
- **Вложенные условия**: `if` внутри другого `if` или `switch-case`.

---

#### **4. Какой подход отражает?**

- **Императивный стиль**: условия управляют выполнением программы явно.
- **Минимизация затрат**: короткое замыкание (`&&`, `||`) экономит вычисления.
- **Чёткие границы решений**: строгая типизация и отсутствие `boolean`-типа (в стандартном C).
- **Система меток (`goto`)**: хотя редко используется, подходит для выхода из глубоко вложенных условий.

#### **7. Примеры использования**

##### **Пример 1: Использование `if`**

```c
#include <stdio.h>

int main() {
    int x = 10;

    if (x > 5) {
        printf("x больше 5\n");
    } else {
        printf("x меньше или равно 5\n");
    }

    return 0;
}
```

##### **Пример 2: Тернарный оператор**

```c
#include <stdio.h>

int main() {
    int a = 10, b = 20;
    int min = (a < b) ? a : b;
    printf("Минимум: %d\n", min);
    return 0;
}
```

##### **Пример 3: `switch-case`**

```c
#include <stdio.h>

int main() {
    int day = 3;

    switch (day) {
        case 1: printf("Понедельник\n"); break;
        case 2: printf("Вторник\n"); break;
        case 3: printf("Среда\n"); break;
        default: printf("Другой день\n");
    }

    return 0;
}
```

##### **Пример 4: `if` внутри цикла**

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            printf("%d - четное число\n", i);
        }
    }
    return 0;
}
```

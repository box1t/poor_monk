Основная проблема шаблонов до С++20 — в них можно было подставить все что угодно, в том числе то, на что они совершенно не рассчитаны. То есть система шаблонов была совершенно нетипизирована. В результате, при передаче в шаблон неверного параметра возникали невероятно длинные и совершенно нечитаемые сообщения об ошибках. С этим пытались бороться с помощью разных языковых хаков, которые я даже упоминать не хочу (хотя приходилось сталкиваться).

Концепты призваны исправить это недоразумение. Они добавляют в шаблоны систему типизации, причем весьма мощную. И вот, разбираясь с особенностями этой системы, я стал изучать доступные материалы в интернете.


Концепт — новая языковая сущность на основе синтаксиса шаблонов. У концепта есть имя, параметры и тело — предикат, возвращающий константное (т.е. вычисляемое на этапе компиляции) логическое значение, зависящее от параметров концепта. Вот так:

```c++
template <int I>
concept Even = I % 2 == 0;

template <typename T>
concept FourByte = sizeof(T)==4;
```

## Использование

  
Основная идея концептов — их можно использовать вместо ключевых слов typename или class в шаблонах. Как метатипы («типы для типов»). Тем самым в шаблоны привносится статическая типизация


```c++
template <FourByte T>
void foo(T const & t) {}
```
Теперь, если мы используем в качестве шаблонного параметра int, то код в подавляющем большинстве случаев скомпилируется; а если double, то будет выдано краткое и понятное сообщение об ошибке. Простая и понятная типизация шаблонов, пока все ок.

## requires expression

  
Сначала рассмотрим requires expression. Идея весьма неплоха: это слово имеет блок в фигурных скобках, код внутри которого оценивается на компилируемость.


К сожалению, слово контекстное и работает только внутри шаблонов, то есть вне шаблона вот такое не скомпилируется:


```c++
bool b = requires { 3.14 >> 1; };
А в шаблоне — пожалуйста:


template<typename T>
constexpr bool Shiftable = requires(T i) { i>>1; };
```


Основное применение requires expression — создание концептов. Например, вот так можно проверить наличие полей и методов в типе. Весьма востребованный кейс.


> requires это не концепт сам по себе.
> это выражение, которое создает концепт.

## requires clause

  
Теперь перейдем к еще одному использованию слова requires — для декларации ограничений шаблонного типа. Это альтернатива использованию имен концептов вместо typename. В следующем примере все три способа эквивалентны:


```c++
// декларация require

template <typename Cont>
	requires Sortable<Cont>
void sort(Cont& container);

// Хвостовая декларация require

template <typename Cont>
void sort(Cont& container) requires Sortable<Cont>;

// Имя концепта вместо typename 
template<Sortable Cont>
void sort(Cont& container)
```


В декларации requires могут использоваться несколько предикатов, объединенных логическими операторами.

```c++
template <typename T>
	requires is_standard_layout_v<T> && is_trivial_v<T>
void fun(T v);
```


## Конъюнкция и дизъюнкция

  
Операторы логической конъюнкции и дизъюнкции выглядят как обычно, но на самом деле работают немного иначе, чем в обычном С++.


Ограничения шаблонов (как функций, так и классов) позволяют ограничить набор возможных типов, которые будут применяться параметрами шаблонов. Добавляя ограничения к параметрам шаблона, решаются следующие задачи:

- Из заголовка шаблона сразу видно, какие аргументы шаблона разрешены, а какие нет.
    
- Шаблон создается только в том случае, если аргументы шаблона удовлетворяют всем ограничениям.
    
- любое нарушение ограничений шаблона приводит к сообщению об ошибке, которое гораздо ближе к первопричине проблемы, а именно к попытке использовать шаблон с неверными аргументами.
    

Начиная со стандарта С++20 в язык был добавлен оператор requires, который позволяет установить для параметров шаблонов ограничения.

|   |   |
|---|---|
|1<br><br>2|`template` `<параметры> requires ограничения`<br><br>`содержимое шаблона;`|

Ограничения представляют условные выражения, которые возвращают значение типа bool - если параметр типа удовлетворяет условию, то возвращается true. Каждое ограничение предписывает одно или несколько требований для одного или нескольких параметров шаблона.

Например, мы хотим определить функцию, которая может складывать числа:

|   |   |
|---|---|
|1<br><br>2<br><br>3<br><br>4<br><br>5<br><br>6<br><br>7<br><br>8<br><br>9<br><br>10<br><br>11|`#include <iostream>`<br><br>`template` `<``typename` `T> requires std::is_same<T,` `int``>::value \| std::is_same<T,` `double``>::value`<br><br>`T sum(T a, T b){` `return` `a + b;}`<br><br>`int` `main()`<br><br>`{`<br><br>    `std::cout << sum(3, 4) << std::endl;`<br><br>    `std::cout << sum(12.5, 4.3) << std::endl;`<br><br>    `//std::cout << sum(5l, 7l) << std::endl;`<br><br>`}`|


Начиная со стандарта C++20 в язык С++ была добавлена такая функциональность как concepts (концепты). Концепты позволяют установить ограничения для параметров шаблонов (как шаблонов функций, так и шаблонов класса).

Концепт фактически представляет шаблон для именованного набора ограничений, где каждое ограничение предписывает одно или несколько требований для одного или нескольких параметров шаблона. В общем случае он имеет следующий вид

|   |   |
|---|---|
|1<br><br>2|`template` `<параметры>`<br><br>`concept имя_концепта = ограничения;`|

Список параметров концепта содержит один или несколько параметров шаблона. Во время компиляции компилятор оценивает концепты, чтобы определить, удовлетворяет ли набор аргументов заданным ограничениям.

`Ограничения` представляют условные выражения, которые возвращают значение типа bool - если параметр типа удовлетворяет условию, то возвращается true.


Простейший пример:

|   |   |
|---|---|
|1<br><br>2|`template` `<``typename` `T>`<br><br>`concept size =` `sizeof``(T) <=` `sizeof``(``int``);`|

В данном случае определен концепт size. Его смысл в том, что тип, который будет передаваться через параметр `T`, должен удовлетворять условию `sizeof(T) <= sizeof(int)`. То есть физический размер объектов типа T не должен быть больше размера значений типа `int`.

Чтобы определить, соответствует ли определенный тип концепту, надо использовать выражение концепта, которое состоит из имени концепта, после которого в угловых скобках указываются аргументы для параметров шаблона.

|   |   |
|---|---|
|1|`имя_концепта<значения_для_параметров>`|

Например, проверим в действии вышеопределенный концепт size:

|   |   |
|---|---|
|1<br><br>2<br><br>3<br><br>4<br><br>5<br><br>6<br><br>7<br><br>8<br><br>9<br><br>10<br><br>11|`#include <iostream>`<br><br>`template` `<``typename` `T>`<br><br>`concept size =` `sizeof``(T) <=` `sizeof``(``int``);`<br><br>`int` `main()`<br><br>`{`<br><br>    `std::cout << std::boolalpha << size<unsigned` `int``> << std::endl;`      `// true`<br><br>    `std::cout << std::boolalpha << size<``char``> << std::endl;`     `// true`<br><br>    `std::cout << std::boolalpha << size<``double``> << std::endl;`   `// false`<br><br>`}`|

В данном случае выражения `size<unsigned int>` и `size<char>` удовлетворяют ограничению концепта, так как применяемые в них типы `unsigned int` и `char` по размеру не превосходят или меньше размера типа int. Поэтому эти выражения возвратят true. А выражение `size<double>` не соответствует ограничению концепта, так как размер типа double больше размера типа int, поэтому это выражение возвратит false

Одни концепты могут основываться на других концептах. Например:

|   |   |
|---|---|
|1<br><br>2<br><br>3<br><br>4<br><br>5<br><br>6<br><br>7<br><br>8<br><br>9<br><br>10<br><br>11<br><br>12<br><br>13<br><br>14<br><br>15<br><br>16|`#include <iostream>`<br><br>`template` `<``typename` `T>`<br><br>`concept small_size =` `sizeof``(T) <` `sizeof``(``int``);`<br><br>`template` `<``typename` `T>`<br><br>`concept big_size =` `sizeof``(T) >` `sizeof``(``long``);`<br><br>`template` `<``typename` `T>`<br><br>`concept size = small_size<T> \| big_size<T>;`<br><br>`int` `main()`<br><br>`{`<br><br>    `std::cout << std::boolalpha << size<unsigned` `int``> << std::endl;` `// false`<br><br>    `std::cout << std::boolalpha << size<``char``> << std::endl;`         `// true`<br><br>    `std::cout << std::boolalpha << size<``double``> << std::endl;`       `// true`<br><br>`}`|

Вначале определяется два простейших концепта. `small_size` требует, чтобы размер типа был меньше размера типа int. А концепт `big_size` требует, чтобы размер типа был больше размера типа long. С помощью стандартных логических операций && и || монжно объединять ограничения. И в данном случае концепт size требует, что тип T удовлетворял либо условию `small_size<T>`, либо `big_size<T>`:

|   |   |
|---|---|
|1|`concept size = small_size<T> \| big_size<T>;`|

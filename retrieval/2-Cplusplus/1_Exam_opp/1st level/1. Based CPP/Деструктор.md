Деструктор - это специальная функция-член, которая вызывается по окончании времени жизни объекта. Цель деструктора - освободить ресурсы, которые объект мог получить за время своей жизни. 

Деструктор вызывается всякий раз, когда заканчивается время жизни объекта, что включает в себя

- завершение программы, для объектов со статической длительностью хранения 
- выход из потока, для объектов с продолжительностью хранения в локальном потоке 

- Деструктор также может быть вызван напрямую, например, для уничтожения объекта, который был создан с помощью placement-new, или через функцию-член аллокатора, такую как std::allocator::destroy(), для уничтожения объекта, который был создан через аллокатор. 
- Обратите внимание, что прямой вызов деструктора для обычного объекта, например локальной переменной, приводит к неопределенному поведению, когда деструктор вызывается снова, в конце области видимости.

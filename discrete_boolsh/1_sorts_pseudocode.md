

## Counting Sort

```
- Шаг 0: На вход - вектор и экспонента
- Шаг 1. Заполняем массив подсчетов вхождениями ЦИФР по разрядам КЛЮЧА входного массива
- Шаг 2. Циклом накапливаем суммы предыдущих элементов 
        - прибавляем к следующему элементу массива подсчетов значение предыдущего элемента
- Шаг 3. В обратном порядке СТРОИМ РЕЗУЛЬТИРУЮЩИЙ массив по разрядам ключа входного массива
        - на месте (понять можно с ручкой)
- Шаг 4. Копируем отсортированные данные обратно в исходный массив


```

## Bucket Sort

```
- Шаг 0: Проверка входных данных на пустоту
- Шаг 1: Инициализация минимального и максимального элементов
- Шаг 2: Инициализация вектора карманов
- Шаг 3: Вычисление ширины кармана
- Шаг 4: Заполнение карманов
    4.1. Вычисляем индекс кармана
    4.2. проходим по входному массиву, вычисляя индексы карманов на его основе
    4.3. Коррекция индекса для максимального элемента
    4.4. Заполняем buckets_vec на основе двойной индексации (понять можно с ручкой и листком бумаги)
- Шаг 5: Сортировка каждого кармана
- Шаг 6: Сборка результата из всех карманов
- Шаг 7: Возвращаем отсортированный вектор

```

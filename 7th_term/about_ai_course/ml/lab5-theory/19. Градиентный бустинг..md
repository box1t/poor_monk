## 1. Градиентный бустинг

Градиентный бустинг — это метод ансамблирования, в котором модели обучаются последовательно. Каждый новый модельный экземпляр исправляет ошибки предыдущих. В отличие от бэггинга, где деревья обучаются независимо, в градиентном бустинге каждое дерево добавляется к ансамблю, чтобы минимизировать остаточную ошибку.

Процесс градиентного бустинга можно описать следующим образом:

* Начинаем с начального предсказания (обычно это среднее значение для задачи регрессии).
* На каждом шаге обучаем новое дерево на остаточную ошибку (разницу между истинным значением и предсказанием текущей модели).
* После обучения дерево добавляется к ансамблю с коэффициентом, уменьшающим его вклад, чтобы не переобучиться на одном шаге.


В основе метода:

* Использование слабых моделей (обычно деревьев решений) для построения ансамбля (**почему?**)
* Постепенное уменьшение ошибки путем оптимизации функции потерь.



Недостатки реализации sklearn:
1. Медленная скорость обучения:

* Реализация в sklearn не оптимизирована для работы с большими объемами данных.
* Время обучения увеличивается с увеличением количества деревьев (n_estimators).

2. Ограниченные возможности:

* Нет поддержки обработки категориальных признаков без предварительного кодирования (get_dummies или OneHotEncoder).
* Нет возможности работы с распределенными вычислениями (не подходит для больших кластеров данных).
* Простая реализация остановки по раннему завершению (early_stopping) может уступать более продвинутым методам.

3. Слабая гибкость:
* Ограниченное количество функций потерь.
* Меньше настроек гиперпараметров по сравнению с библиотеками, такими как XGBoost, LightGBM или CatBoost.

Короче, всё плохо с sklearn!

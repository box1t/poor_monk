### Accuracy (доля правильных ответов)

Данная метрика является самой тривиальной метрикой задачи классификации и представляет собой долю правильных ответов:

$$Accuracy(y, \hat{y}) = \frac{1}{N} \sum\limits_{i=1}^{N}I\{y_i = \hat{y}_i\} $$

где $y$ - вектор истинных классов, $\hat{y}$ - вектор предсказанных классов, $N$ - количество элементов в наборе данных.

**Достоинство:** в основе метрики лежит простая интуиция. Легко интерпретировать.

**Недостатки:** данная метрика совершенно не пригодна в случае дисбалансов классов, когда представителей одного класса существенно больше другого.

Рассмотрим пример выборки, в которой 950 положительных и 50 отрицательных объектов. Если построить простейший классификатор, который всегда предсказывает первый класс, то Accuracy такого алгоритма будет составлять целых *95%*, хотя он не несет абсолютно никакой пользы практически



### Confusion Matrix

Рассмотрим матрицу ошибок(Confusion Matrix) - матрицу размера 2х2, где $i,j$-я позиция равна числу объектов $i$-го класса, которым модель присвоила метрку $j$-го класса. Данное понятие нужно осознать и запомнить, так как на основе данной матрицы будут введены более сложные метрики.

<img src="https://miuul.com/image/article/62913c3a26d73.png" style="height:300px">

- **TN** - True Negative, каличество верно(True) предсказанных объектов среди тех, которым модель присвоила негативный(Negative) класс.
- **FP** - False Positive, каличество неверно(False) предсказанных объектов среди тех, которым модель присвоила позитивный(Positive) класс.
- **FN** - False Negative, каличество неверно(False) предсказанных объектов среди тех, которым модель присвоила негативный(Negative) класс.
- **TP** - True Positive, каличество верно(True) предсказанных объектов среди тех, которым модель присвоила позитивный(Positive) класс.

Отмечу, что в данной терминологии $accuracy$ можно представить через такую формулу:

$$accuracy = \frac{TP+TN}{TP+TN+FP+FN}$$

#### Пример

Пусть мы хотим оценить работу спам-фильтра почты. У нас есть 100 не-спам писем, 90 из которых наш классификатор определил верно и 10 спам-писем, 5 из которых классификатор также определил верно. Будем считать класс не-спам писем отрицательным, а класс спам писем - положительным. Обозначим количество объектов отрицательного класса $N_0$, а положительного $N_1$, тогда:

$$N_0 = TN + FP = 100$$
$$N_1 = TP + FN = 10$$

Итого: 
- Из 100 не-спам писем 90 были определены верно -> $TN = 90, FP = 10$
- Из 10 спам писем 5 было определено верно -> $TP = 5, FN = 5$

Данная матрица сама по себе является не метрикой, а инструментом для ввода новых продвинутых метрик и анализа.

### Precision(точность)

Точность показывает какой процент объектов, которые метод посчитал положительными, действительно являются положительными:

$$precision(y, \hat{y})=\frac{TP}{TP+FP}$$

где $y$ - вектор истинных классов, $\hat{y}$ - вектор предсказанных классов.

**Пример:**

Рассмотрим задачу предсказания реакции клиента банка на звонок с предложением кредита. Класс $y = 1$ означает, что клиент возьмет кредит после рекламного звонка, класс $y=-1$, что не возьмет. Планируется обзванивать только тех клиентов, которых классификатор отнесет к классу $1$. Если классификатор имеет высокую точность, то практически все клиенты, которым будет сделано предложение, откликнутся на него.

**Достоинство:** позволяет следить за тем, насколько можно доверять модели, если она предсказывает позитивный класс.

**Недостаток:** не позволяет следить за тем, как много положительных объектов способен потерять классификатор.


### Recall (полнота)

Полнота показывает какую долю объектов положительного класса модель классифицировала правильно:

$$recall(y, \hat{y})=\frac{TP}{TP+FN}$$

где $y$ - вектор истинных классов, $\hat{y}$ - вектор предсказанных классов.

**Пример:**

Рассмотрим тот же пример предсказания реакции клиента банка на телефонный звонок с предложением кредита. Если классификатор имеет высокую полноту, то предложение будет сделано практически всем клиентам, которые готовы откликнуться на него.

**Достоинство:** позволяет следить за тем, как много положительных объектов способен распознать классификатор.

**Недостаток:** не позволяет следить за тем, насколько можно доверять модели, если она предсказывает позитивный класс.

### $F_1$-мера



Хотелось бы получить один критерий, который учитывал бы в себе и точность и полноту. Существует несколько способов получить один критерий качества на основе точности и полноты. Один из них - $F_1$-мера, гармоническое среднее точности и полноты:

$$F_1 = \frac{2 \times precision \times recall}{precision + recall}$$

Среднее гармоническое обладает важным свойством - оно близко к нулю, если хотя бы один из аргументов близок к нулю. При этом $F_1$ достигает максимума при $precision = 1$ и $recall = 1$.

*Замечание*

Иногда ее называют $F$-мерой.

### $F_\beta$-мера

Обобщением $F_1$-меры является $F_\beta$-мера, которая равна взвешенному гармоническому precision и recall с коэффициентом $\beta$:

$$F_\beta = (1+\beta^2)\frac{precision \times recall}{\beta^2 precision + recall}$$

В данном случае $\beta$ определяет вес точности в метрике.

$0 < \beta < 1$ -> важнее precision

$1 < \beta < +\inf$ -> важнее recall



### Обобщение метрик классификации на многоклассовый случай


Как правило обобобщением метрик является усреднение метрик бинарной классификации.

Бывает 2 вида усреднения: микро-усреднение и макро-усреднение

1. Микро-усреднение: считаем характеристики (например TP, FP, TN, FN) для бинарной классификации(один класс против всех остальных) и усредняем их по всем классам. После этого считаем итоговую метрику по усредненным характеристикам. Например формула точности примет вид:

$$ precision = \frac{\overline{TP}}{\overline{TP}+\overline{FP}} $$

где $\overline{TP}=\frac{1}{K}\sum\limits_{k=1}^K TP_k$

2. Макро-усреднение: для каждого класса считаем итоговую метрику как для бинарной классификации (один класс против всех). После этого усредняем итоговую метрику по всем классам. Например, точность будет вычислена как: 

$$precision = \frac{1}{K}\sum\limits_{k=1}^K precision_k$$

где $precision_k = \frac{TP_k}{TP_k+FP_k}$

Важный нюанс: если наша модель работает с маленькими классами, то предпочтительно отдавать выбор в сторону макро-усреднения, так как микро-усреднение плохо работает с маленькими классам. Макро-усреднение обладает свойством отсутствия влияния размеров классов на итговый результат. Все классы вносят одинаковый вклад в метрику

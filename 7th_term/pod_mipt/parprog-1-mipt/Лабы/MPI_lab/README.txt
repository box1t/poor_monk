run.sh - для запуска одного приложения
run_Lab_1.sh - для запуска первой лабы (метод левого треугольника) для 
	n-ядер = {1,2...10}
	
	вычислительной нагрузке U = U1*U2	  
	U1(t=const) ~ 1Nx 		
	dx = x2 - x1 = X/Nx; x=[0,X], X=10? 
	
	U2(x=const) ~ {1Nt, 2Nt...10Nt}		
	dt = t2 - t1 = T/Nt; t=[0,T], T=1
Получается сетка 10 на 10: F(n,U) = Время исполнения(n-ядер, Лин.Возр.Нагрузке)

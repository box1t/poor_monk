
### 3. Subgenerator
A **subgenerator** is a generator that is invoked from another generator using the `yield from` expression. This allows the main generator to delegate part of its operations to another generator.

```python
def subgenerator():
    yield 1
    yield 2

def main_generator():
    yield from subgenerator()
    yield 3

gen = main_generator()
for value in gen:
    print(value)
# Output: 1, 2, 3
```

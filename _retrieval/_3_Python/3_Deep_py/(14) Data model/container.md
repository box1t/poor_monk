### 6. Container
A **container** in Python is a data structure that holds and organizes multiple items. Examples include lists, tuples, dictionaries, and sets. Containers are essential for grouping multiple values, accessing them via indexing, iterating over them, and manipulating collections of data.

**Examples**:
- **List**: An ordered collection of items.
  ```python
  my_list = [1, 2, 3]
  ```
- **Tuple**: An ordered, immutable collection of items.
  ```python
  my_tuple = (1, 2, 3)
  ```
- **Dictionary**: A collection of key-value pairs.
  ```python
  my_dict = {'a': 1, 'b': 2, 'c': 3}
  ```
- **Set**: An unordered collection of unique items.
  ```python
  my_set = {1, 2, 3}
  ```

These data structures provide various methods and operations for managing collections of data efficiently.



Тип данных ***дерево*** обычно отсутствует в ЯП.
Ввиду сложности и многообразия деревьев нет и стандартных пакетов для их описания.
Поэтому мы реализуем их сами.

Создадим дерево с двузвенным ветвлением, ведь в нём трудно ошибиться.


# Построение и визуализация дерева

1. Зададим структуру узла `Node` 
Она хранит три элемента: `key` для значения узла, `left` и `right` для указания на дочерние узлы.
2. Для удобства создается `typedef` `NodePtr` как указатель на структуру `Node`.
3. Функция `buildTree` принимает на вход целое число `numNodes` и возвращает указатель на корень построенного дерева. Она рекурсивно строит дерево в зависимости от количества узлов.

   - Если `numNodes` равно 0, что указывает на пустое дерево, функция возвращает `NULL`.
   - В противном случае она считывает символьное значение из входных данных с помощью `scanf` и присваивает его члену `key` вновь созданного узла.
   - Она подсчитывает количество узлов для левого поддерева (`leftNumNodes`) и правого поддерева (`rightNumNodes`).
   - Рекурсивно вызывает `buildTree` для построения левого поддерева и присваивает возвращенный указатель члену `left` текущего узла.
   - Он рекурсивно вызывает `buildTree` для построения правого поддерева и присваивает возвращенный указатель члену `right` текущего узла.
   - Наконец, он возвращает указатель на текущий узел.
4. Функция `printTree` принимает указатель на корень дерева (`tree`) и целое число `height` для представления текущей глубины дерева. Она выполняет последовательный обход дерева для печати узлов в визуальном формате.

   - Если указатель на дерево не является `NULL`, функция рекурсивно вызывает `printTree` для левого поддерева, увеличивая `height` на 1.
   - Затем она печатает отступ (`\t`), основанный на текущей `высоте`, чтобы представить глубину узла.
   - Он печатает `ключ` текущего узла, за которым следует символ новой строки.
   - Наконец, он рекурсивно вызывает `printTree` для правого поддерева, увеличивая `высоту` на 1.

5. В функции `main`:
   - Она считывает целочисленное значение `numNodes` из входных данных с помощью `scanf`.
   - Вызывает функцию `buildTree`, передавая `numNodes`, и присваивает возвращенный указатель переменной `root`.
   - Она вызывает функцию `printTree`, передавая `root` и начальную `высоту` равную 0, чтобы распечатать структуру дерева. 



Программа напечатает ascii-визуализацию дерева, лежащего на боку, с сохранением топологии, но без графических излишеств в виде рёбер и кружков.


Программа считывает количество узлов и их значения из входных данных и строит двоичное дерево на основе входных данных. Затем она печатает дерево в визуальном формате, выполняя обход по порядку.

```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    char key;
    struct Node* left;
    struct Node* right;
};
typedef struct Node* NodePtr;

NodePtr buildTree(int numNodes) {
    if (numNodes == 0) {
        return NULL;
    } else {
        int leftNumNodes = numNodes / 2;
        int rightNumNodes = numNodes - leftNumNodes - 1;
        char value;
        scanf(" %c", &value);
        NodePtr newNode = (NodePtr)malloc(sizeof(struct Node));
        newNode->key = value;
        newNode->left = buildTree(leftNumNodes);
        newNode->right = buildTree(rightNumNodes);
        return newNode;
    }
}
void printTree(NodePtr tree, int height) {
    if (tree != NULL) {
        printTree(tree->left, height + 1);
        for (int i = 0; i < height; i++) {
            printf("\t");
        }
        printf("%c\n", tree->key);
        printTree(tree->right, height + 1);
    }
}
int main() {
    int numNodes;
    scanf("%d", &numNodes);
    NodePtr root = buildTree(numNodes);
    printTree(root, 0);
    return 0;
}

```

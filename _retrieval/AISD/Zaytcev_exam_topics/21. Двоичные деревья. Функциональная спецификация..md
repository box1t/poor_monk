

Дерево - структура, которая образована элементом типа Т, называемым корнем дерева, и конечным (возможно пустым) множеством с переменным числом элементов - деревьев типа Т, называемых поддеревьями.

Дерево без поддеревьев образует простейшее дерево с одним уровнем.

Деревья принято рисовать вверх корнем (как генеалогическое или династическое дерево).

Определения, относящиеся к деревьям:

1. Узлы (вершины) - элементы типа Т, входящие в дерево
2. Степень узла - число поддеревьев данного узлла
3. Лист, или концевый узел - узел без поддеревьев
4. Узла разветвления (внутренние) - неконцевые узлы
5. Уровень узла в дереве рекурсивно определяется так: корень имеет уровень 1, корень каждого поддерева имеет больший на единицу уровень.
6. Глубина - наибольшее значение уровня вершины. Внутренние вершины дерева не находятся на максимальном уровне.

Для описания узлов используют лица по мужской линии (отец, сын), но ***вершины дочерние***.
Сыновья одного узла - ***братья***.

Степень - число вершин разветвления.
Степень дерева - ширина (но реально - максимальная степень всех его вершин)

Листья (концевые узлы, терминальные) - вершины, у которых нет потомков.

Любая вершина является корнем поддерева, которое растёт из него.

Сыновья упорядочиваются слева направо.
Чем меньший номер сына, тем он старше.

Такие деревья называем деревьями общего вида.
Эти деревья - непустые структуры (минимум один элемент - корень) с многозвенным разветвлением каждой вершины на непересекающиеся поддеревья.

Среди структур данных деревья наиболее приспособлены для решения задач ИИ и синтаксического анализа.

***
## Двоичные деревья

Бинарное дерево - конечное множество узлов, которое или ***пусто***, или состоит из двух непересекающихся поддеревьев (того же типа), называемых левым и правым поддеревьями данного узла. 

Определение дерева рекурсивно. и само по себе дерево - рекурсивная структура!

Это не частный случай дерева общего вида, а особый вид структуры данных.

- В бинарном дереве важен наклон ветвей, а в обычно он несущественен.
- Бинарное дерево, в отличие от обычного, может быть пустым.

В практике программирования обычные деревья часто представляются с помощью специальных классов бинарных деревьев, т.к. их проще хранить и обрабатывать.

Примеры деревьев:
- родословная - родители каждого человека изображаются как его потомки
- схема спортивного турнира

Двоичное дерево определяется так:
- Создать
- Построить
- Пусто
- Корень
- Слева
- Справа
- Уничтожить

Каждое дерево получено построением из своего корня.
Левое поддерево имеет своё левое поддерево, а правое поддерево - своё правое.

В зависимости от решаемых задач предусматриваются разные операции, такие как присоединение к узлу поддерева, удаление поддерева или замена поддерева на новое.

Тип данных узла двоичного дерева:

```c
struct node {
	char key;
	struct node* left;
	struct node* right;
}
```

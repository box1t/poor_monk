

Итераторы - это структуры для итерационно повторяющейся обработки последовательных структур.

***Итератор*** предназначен для навигации по списку, чтения и перезаписи его элементов.

Способы инициализации итератора:
1) В результате присваивания получим значение ранее созданного итератора.
2) С помощью функции работы со списком "ПЕРВЫЙ" и "ПОСЛЕДНИЙ"


- Функция ПЕРВЫЙ возвращает итератор, который указывает на элемент.
- Функция ПОСЛЕДНИЙ выдаёт не последний элемент списка, а итератор, указывающий на фиктивный элемент после конца списка - ***терминатор***.



```c

// Пусть l - некоторый (возможно) пустой список
Iterator i, last = Last(&l); // Элемент после конца  

for(i = First(&l); NotEqual(i, last); Next(&i))
{
	// Действие со списком
}
```

==списочные задачи эффективны, когда часто работаем с локальными элементами.==

Скорость работы проверяется в функциях модификации списка:

==линейное время вставки и удаления в списке значительно дешевле. это плата за произвольность вставки и удаления.==

***
Приступим к программированию итераторов.
Сначала опишем тип элементов двунаправленного списка, указываемых итераторами:

```c

struct Item
{
	struct Item* prev;
	struct Item* next;
	T data;
};

```

Итератор всего лишь указывает на некоторый элемент.


```c

typedef struct
{
	Item* node;
} Iterator;

```

> Просто так увеличивать адрес и получать следующий элемент списка нельзя, поскольку необязательно, что элементы хранятся в памяти последовательно. 


Следуя функциональной спецификации, опишем функции сравнения итераторов на равенство и неравенство. Они равны, когда указываются на один и тот же элемент:

```c

bool Equal(const Iterator* lhs, const Iterator* rhs)
{
	return lhs->hode == rhs->node;
}

bool NotEqual(const Iterator* lhs, const Iterator* rhs)
{
	return !Equal(lhs, rhs);
}

```
==вставка идёт по значению!==

- *NotEqual()* проясняет и упрощает условия ветвлений и циклов в Си.

***
 - *Next()* продвигает итератор к следующему элементу списка.

```c

Iterator Next(Iterator* i)
{
	i->node = i->node->next;
	return i;
}

```

***
- Функция *Prev()* - зеркальное отражение функции *Next()*:
```c
Iterator Prev(Iterator* i)
{
	i->node = i->node->prev;
	return i;
}

```

***
- ***Fetch()*** нужна для чтения элементов списка, на который указывает итератор.
```c

T Fetch(const Iterator* i)
{
	return i->node->data;
}

```

***
- Противоположная для ***Fetch()*** функция ***Store()*** позволяет записать данные в элемент списка.
```c

void Store(const Iterator* i, const T t)
{
	i->node->data = t;
}

```

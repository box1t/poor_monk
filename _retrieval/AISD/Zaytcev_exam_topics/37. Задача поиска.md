# Линейный поиск

**

Поиск часто применяется в программах. 

Простейшая задача поиска - поиск слова в текстовом файле, + поиск в интернете

  

При рассмотрении алгоритмов поиска будем считать, что множество данных, в которых будет осуществляться поиск, фиксировано. 

  

Линейный поиск:

Последовательный просмотр всех элементов массива. Сложность линейная - О(n). 

x - искомое значение

a - массив данных 

i=0;

while (x!=a[i] && i<N){

i++;

}

2 условие нужно для того, чтобы если элемент в списке отсутствует цикл не ушел в бесконечность 

для упрощения условия цикла можно добавить в конец массива 1 элемент = а(барьерный элемент )

Это единственный метод поиска для структур данных с последовательным доступом.

# Двоичный поиск

**

Двоичный поиск(метод половинного деления, дихотомия):

Работает в упорядоченном множестве и с структурами данных с произвольным доступом(массив)

Сложность О(Log n) 

Идея: берем середину массива и сравниваем его значение с искомым значением, если оно меньше , берем половину левой половины, если больше

int L=0;

int R=n-1;

bool found=false;

while(L<=R && !found){

m=(L+R)/2 +1;

}

Этот поиск эффективнее линейного, и в сравнении с таблицами(у которых много ссылок) занимает меньше памяти, также эффективен как и бинарное дерево поиска

**


```c++

## 1. Find a number (basic BS)

int binarySearch(const int& data, int target) {
	int left = 0;
	int right = data.length - 1; // pay attention!!!
	while (left <= right) {
		int mid = (left + right) / 2;
		if(data[mid] == target) {
			return mid;
		} else if(data[mid] < target) {
			left = mid + 1;
		} else {
			right = mid - 1;
		}
	}
	return -1;
}
```

# Поиск в таблице!

Таблица - прямоугольная структура данных из строк.
В ней есть поля ключей, а есть полезные поля данных.
Ищем по ключам, а находим спрятанные за ключами данные.

Ключ является составным. 
Ключ это слово или строка.

Строки совпадают, если совпадают по длине, и литеры совпадают поиндексно.
Удобно использовать строки переменной длины.

На СИ строки переменной длины, их размер явно не указан.
Это обеспечивает сравнение и копирование быстрым барьерным методом.

Барьер - терминирующий элемент строки chr(0)

Для поиска в таблице последовательно сравниваем компоненты ключа при помощи цикла с предусловием и терминирующего элемента строки.

При помощи двоичного поиска мы получим указатель на найденный элемент или NULL, если элемент не найден.
Двоичный поиск принимает указатель на ключ и указатель на элемент, с которого начинаем поиск.


> Сравнить многочлены.
> Дадим определение равенства многочленов.
> Тип одинаковый
> Степень многочлена одинакова.
> Многочлены равны, если коэффициенты при степенях попарно равны.

> Строки бывают переменной длины для цикла while, для for - постоянную длину.



Если у дерева для каждой вершины все ключи левого поддерева меньше правых, а правые больше левых, то дерево называется деревом поиска.

Переходя к одному поддереву, мы исключаем другое, содержащее половину узлов.
Дихотомия обеспечивает эффективное время поиска: если всё просуммировать, получим логарифм.
Число вершин для сбалансированного двоичного дерева не может быть больше его глубины, оцениваемой в логарифм по осн. 2. 
Поэтому деревья дают большой выигрыш во времени поиска.

Поиск идёт от корня дерева и до его листа по однозначно выбираемому пути, значит для реализации достаточно цикла с предусловием (рекурсия и стек не нужны):

```c
p* locate(int x, p* t) {
	while (t != NULL && t->key != x) {
		if (t->key < x) {
			t = t->right;
		} else {
			t = t->left;
		}
	}
	return t;
}
```

В случае неуспеха вернётся значение NULL.

Дерево поиска используется для упорядочивания данных.
Мы размещаем их в дереве поиска, а в результате обхода составляем упорядоченную последовательность. При этом не должны входить равнозначные элементы.

```c++
    BstNode* newNode = new BstNode();
    newNode->data = data;
    newNode->left = newNode->right = nullptr;
    return newNode;
}

BstNode* Insert(BstNode* root, int data) {
    if (root == nullptr) {
        root = GetNewNode(data);
```

### Поиск минимального/максимального элемента в бинарном дереве поиска

```c++
#1. Find MIN (iterative)

struct BstNode {
	int data;
	BstNode* left;
	BstNode* right;
};

int FindMin(BstNode* root) {
	if(root == nullptr) {
		std::cout << "Tree is empty" << std::endl;
		return -1;
	} 
	while (root->left != nullptr) {
		root = root->left;
	} 
	return root->data;
}
		
#2. Find MAX (iterative)

struct BstNode {
	int data;
	BstNode* left;
	BstNode* right;
};

int FindMax(BstNode* root) {
	if(root == nullptr) {
		std::cout << "Tree is empty" << std::endl;
		return -1;
	} 
	while (root->right != nullptr) {
		root = root->right;
	} 
	return root->data;
}

#3. Find Min(recursive)


struct BstNode {
	int data;
	BstNode* left;
	BstNode* right;
};

int FindMin(BstNode* root) {
	if(root == nullptr) {
		std::cout << "Tree is empty" << std::endl;
		return -1;
	} 
	else if(root->left != nullptr) {
		return root->data;
	} //search in the left subtree
	return FindMin(root->left);
}
```

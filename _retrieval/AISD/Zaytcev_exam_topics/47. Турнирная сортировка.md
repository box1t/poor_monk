

Сортировка выборкой была основана на повторяющемся поиске наименьшего ключа в сокращающейся последовательности элементов.

Тем не менее, число сравнений остается квадратичным.

Причина трудоемкости выборки в том, что при поиске минимального элемента на каждом проходе теряется ценная информация о других почти минимальных жлементах.
Сам поиск линейный.

Если сравнивать пары соседних элементов, то в результате n/2 сравнений получим то же число элементов с наименьшими ключами - число победителей.

Проделав n-1 сравнение, получим дерево выбора минимального элемента.

Дерево выбора сохраняет турнирную историю.
История может быть использована для сокращения перебора.

При этом мы сохранили иерархию, локально минимальных элементов, которая теряется при сортировке выборкой.

Для этого от победителя отправляемся к призерам, осуществив спуск вдоль пути, отмеченного наименьшим элементом.

Следы его пути отметим пустыми элементами.
Поднимаясь назад, определим победителя.
Элемент, соревнующийся с пустым местом, автоматически переходит в следующий тур.

В результате в корень переместится наименьший из оставшихся элементов.

Повторяя процесс до полной выемки непустых элементов из дерева, получим отсортированную последовательность.

Дерево выбора эффективно реализуется на очереди с приоритетом.
Наибольший приоритет отдаётся наименьшему ключу элемента, помещаемому в вершину дерева.


Сложностная оценка:

На каждом из n шагов требуется log2n + 1 сравнений (высота дерева).

Общее число сравнений - nlog2n.

Оценим стоимость построения дерева.
Оценивается в n шагов.

Общая оценка остаётся линеарифмической.
Это существенно лучше даже шелловских n^1 + Б.

Теперь возникает вопрос размещения дерева.
Он требует двойного расхода памяти: сначала размещаются участники турнира, потом - победители пар, за ними - победители победителей.

Для полного турнирного дерева с 2^K участниками требуется 2^K-j-1 в качестве базового адреса, где j - номер уровня.


Из-за дублирования в дереве выбора победивших жлементов пространственная сложность алгоритма возрастает вдвое.

Дек - двухсторонняя очередь, динамическая структура данных, в которой элементы можно удалять и добавлять как в начало, так и в конец.

Внутри дека - труба, работает за линейное время.

Операции над деком:
- включение элемента справа.
- влючение элемента слева
- исключение элемента справа
- исключение элемента слева
- определение размера
- очистка

# Реализация Дека на Си 

```c
// 1. Описание структуры данных

typedef struct Item {
	int data; // Хранимое значение
	struct Item* next; // указатель на след
	struct Item* prev; // указатель на пред
} Item;

typedef struct deque {
	Item *left; // указатель на левый конец
	Item *right; // указатель на правый конец
	int size; // размер дека
} deque;

// 2. Функциональная спецификация

deque* СreateDeque(vector* v); // создание дека из вектора
bool isEmptyDeque(deque* d); // проверка на пустоту
bool PushLeftDeque(deque* d, int i); // добавить элемент слева
bool PushRightDeque(deque* d, int i); // добавить элемент справа
bool PopLeftDeque(deque* d); // удалить элемент слева
bool PopRightDeque(deque* d); // удалить элемент справа
int TopLeftDeque(deque* d); // посмотреть элемент слева
int TopRightDeque(deque* d); // посмотреть элемент справа
bool DeleteDeque(deque* d); // очистить дек

```

# Примеры задач

### 1. Задача моделирования железнодорожного проезда 

Поезда с вагонами - идеальные примеры для очередей. 
В бок вагоны не ездят. Поезд это дек из вагонов! 

Обычная очередь неточно описывает вагон. Если мы хотим отцепить последний вагон, увозим поезд. Если отцепить первый вагон - надо отцепить локомотив и отвезти. 

Но отцепить и прицепить - это дек. 
Получается, алгебру поездов можно реализовать деком.

Если мы хотим переставить объекты, то должны отцеплять вагоны с начала и загонять их в тупик 
(в стек), пока не найдём нужный вагон. 

Сломанный вагон отцепили, потушили, он в поезде не участвует. 
А потом ставим вагоны снова  в начало

### 2. Нелинейный видеомонтаж

Раньше на магнитных лентах были куски фильмов, которые вырезали и вставляли куда-то. 
Деки позволяют монтировать фильмы на кассетах - копировать с одной на другую.

### 3. Задача про зоопарк

Обычная очередь неполноценна: в ней можно ползти только вперед.
Это крокодилова труба: в очереди крокодилы назад не ползают.

В двухконцовой очереди концы открыты на вход и выход.  
Там крокодилы назад ползают. И тогда все звери могут вернуться к водопаду.

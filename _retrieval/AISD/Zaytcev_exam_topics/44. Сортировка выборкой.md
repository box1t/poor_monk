

Алгоритм основан на простой идее:
- отыскивается элемент с наименьшим ключом
- меняется местами с первым элементов.
- процесс повторяется, пока не останется самый большой элемент.


Выборка противоположна вставке.

При прямой вставке на каждом шаге рассматривается только один очередной элемент исходной последовательности и ВСЕ элементы готовой, где ищем место вставки.

При прямом выборе для поиска одного элемента с наименьшим ключом просматриваем все элементы исходной последовательности.
Найденный минимальный помещается в выходную последовательность как очередной элемент.

Выборка выполняется на месте. Обмен возможен ввиду прямого доступа к элементам.

Доказательство корректности осуществляется по индукции.

Сложность алгоритма - O(ln n + g), где g = 0.57 - константа Эйлера.

Сортировка выборкой предпочтительнее простой вставки.
Вставка выигрывает только при почти полном и полном упорядочивании.

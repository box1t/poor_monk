# Метафункции (type traits)

Метафункция - функция, которая принимает в аргумент ТИПЫ.

Допустим, мы хотим написать функцию с двумя параметрами: 


```c++
// Мы хотим проверять, совпадают ли типы Т и U. Но просто так это не работает.
// Мы напишем функцию, которая работает в compile-time и осуществляет эту проверку

template <typename T, typename U>
void f(T x, U y) {
	if (T == U) {
			
	}
}

// Все метафункции - это на самом деле структуры.

template <typename T, typename U>
struct is_same {
	static const bool value = false;
};
// У нас есть общая версия метафункции (структуры). Принимает 2 шаблонных типа.
// По умолчанию храним, что value = false

// Дальше пишем специализацию, в которой 2 одинаковых типа.
template <typename T>
struct is_same<T, T> {
	static const bool value = true;
};

// Дальше как этим пользоваться:

template <typename T, typename U>
void f(T x, U y) {
	if(is_same<T, U>::value) // синтаксис вызова статического поля
	{ // Value is true when T and U are equal
		std::cout << 1;
	}
	else {
		std::cout << 2;
	}
}
```



# Метафункция возвращающая разный тип данных в зависимости от условия

2. Простейшие метафункции
метафункция – это шаблон класса,
параметры метафункции – это параметры этого шаблона класса, в качестве них
могут передаваться или целочисленные константы, значения которых известны
во время компиляции, или типы.


Факториал
Пусть число N известно во время компиляции. Тогда значение N! во
время компиляции можно вычислить с помощью следующей метафункции:

```c++
template <unsigned N>
struct factorial {
	static const unsigned value = N * factorial<N-1>::value;
};
template <>
struct factorial<0> {
	static const unsigned value = 1;
};


const unsigned f5 = factorial<5>::value; // 120
```

Первый шаблон класса factorial является общим случаем и реализует
рекурсивный вызов по известному правилу. Второй класс – это т.н. «полная
специализация» шаблона класса и служит для завершения рекурсии. Результат
метафункции хранится в static const переменной value типа unsigned. Если
число N окажется сслишком большим, то результат в переменную типа unsigned
не поместится.

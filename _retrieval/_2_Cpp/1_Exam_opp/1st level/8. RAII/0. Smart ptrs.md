

## "Умные" указатели

Умные указатели предотвращает утечки памяти. Представляют собой классы, обеспечивающие управление временем жизни объектов.


```c++

Заготовка умного указателя:

template <typename T>
struct SmartPtr {
	T* ptr;
		SmartPtr() : ptr(nullptr){}
	SmartPtr(T* ptr) : ptr(ptr) {}
	~SmartPtr() {
		delete ptr;
	}
};


// Теперь при использовании SmartPtr все будет хорошо.
// Если мы успели создать этот объект, он внутри себя захватил ресурсы.
// А так как мы успели создать, во время исключения он уничтожится.
// То есть вызовется его деструктор.
// А если создать не успели, то и деструктор не вызван.
// Значит и удалять нечего.



struct S{
	SmartPtr<int> ptr;
	S() : ptr(new int(5)) {
		throw 1;
	}
};


// В конструкторе инициализируется указатель при вызове структуры.
// И получение в этот же момент.
// Получаем ресурс в виде указателя и сразу его инициализируем через созданный указатель.
// Конструктор не успел завершиться. Значит, объект не является созданным.
// Значит, у него и не вызывается деструктор.

```

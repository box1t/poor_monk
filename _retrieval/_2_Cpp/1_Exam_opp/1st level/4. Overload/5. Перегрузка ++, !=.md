Перегрузка операторов. Синтаксис. Возможные к перегрузке операции. Перегрузка ++ и --. Перегрузка бинарных операторов.

```c++
у++ - постинкремент. инкрементирует у, но возвращает старое значение.
эта штука не может возвращать ссылку. она возвращает ЗНАЧЕНИЕ.

++у - преинкремент. инкрементирует у и возвращает новое значение.
он должен возвращать ССЫЛКУ НА СЕБЯ


Quat<T>& Quat<T>::operator++(); // возвращает ссылку. значит, это преинкремент
Quat<T> Quat<T>::operator++(int); // post-increment


```

```c++
template<typename T> struct Quat {
	T x_, y_, z_, w_;
	Quat<T>& Quat<T>::operator++() { x_ += 1; return *this;}

	Quat<T> Quat<T>::operator++(int) {
		Quat<T> tmp {*this}; // copy current value
		++(*this);
		return tmp; // return copy
	}
};
```

Поскольку все операторы сравнения являются бинарными и не изменяют свои левые операнды, то выполнять [**перегрузку следует через дружественные функции**](https://ravesli.com/urok-131-peregruzka-operatorov-cherez-druzhestvennye-funktsii/).

Например, **перегрузим оператор равенства** `==` **и оператор неравенства** `!=` для класса Car:

```c++
#include <iostream>
#include <string>
class Car {
private:
    std::string m_company;
    std::string m_model;
public:
Car(std::string company, std::string model): m_company(company), m_model(model){}
    friend bool operator== (const Car &c1, const Car &c2);
    friend bool operator!= (const Car &c1, const Car &c2);
};
bool operator== (const Car &c1, const Car &c2) {
    return (c1.m_company == c2.m_company && c1.m_model== c2.m_model);
}
bool operator!= (const Car &c1, const Car &c2) {
    return !(c1== c2);
}

```

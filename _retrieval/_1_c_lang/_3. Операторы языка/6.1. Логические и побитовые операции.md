### **Вопросы по тексту:**

1. Какие операции относятся к логическим?
2. Как определяется истина и ложь для скалярных операндов?
3. Что такое «короткая» логика и как она работает?
4. Почему в выражении `if (n != 0 && b > a/n)` исключается деление на ноль?
5. Как работает последовательность вычислений в примере с `getchar()` и `isprint()`?

---

### **Ключевые моменты текста:**

1. **Логические операции:**
    
    - Отрицание `!`, конъюнкция `&&` и дизъюнкция `||`.
    - Результат операций — единица (истина) или ноль (ложь).
2. **Истина и ложь для скалярных операндов:**
    
    - Истина: любое ненулевое значение.
    - Ложь: только ноль.
3. **«Короткая» логика:**
    
    - Операнды вычисляются слева направо.
    - Если результат операции можно определить после первого операнда, второй операнд не вычисляется.
        - Для `&&` вычисление второго операнда пропускается, если первый равен нулю (ложь).
        - Для `||` вычисление второго операнда пропускается, если первый равен единице (истина).
4. **Пример 1:**
    
    - В выражении `if (n != 0 && b > a/n)`:
        - Сначала проверяется условие `n != 0`.
        - Если `n == 0`, второе условие `b > a/n` не будет вычислено, что предотвращает деление на ноль.
5. **Пример 2:**
    
    - В выражении `if ((c = getchar()) != EOF && isprint(c))`:
        - Функция `getchar()` вызывается первой, и её результат записывается в переменную `c`.
        - Если `c == EOF`, вызов `isprint(c)` не производится.
        - Гарантируется, что побочный эффект (присваивание значения переменной `c`) завершится до вычисления второго операнда.

### **Вопросы по тексту:**

1. Какие операции относятся к побитовым, и как они классифицируются?
2. Какое поведение характерно для побитового сдвига вправо для знаковых и беззнаковых операндов?
3. Почему для побитовых операций рекомендуется использовать беззнаковые типы?
4. Как обнулить все биты, кроме младших трёх, для переменной `x`?
5. Как установить младшие пять битов у переменной `x` без использования констант?

---

### **Ключевые моменты текста:**

1. **Классификация побитовых операций:**
    
    - **Одноместные операции:**
        - Инверсия (`~`).
    - **Двухместные операции:**
        - Побитовое И (`&`).
        - Побитовое включающее ИЛИ (`|`).
        - Побитовое исключающее ИЛИ (`^`).
        - Побитовые сдвиги:
            - Влево (`<<`).
            - Вправо (`>>`).
2. **Особенности побитовых сдвигов:**
    
    - **Сдвиг на отрицательное число бит** или на значение, превышающее ширину первого операнда, — **не определён** (undefined behavior).
    - **Сдвиг вправо:**
        - Для **беззнаковых операндов** освобождающиеся биты всегда заполняются нулями.
        - Для **знаковых операндов** поведение зависит от реализации:
            - Логический сдвиг: заполнение нулями.
            - Арифметический сдвиг: заполнение значением знакового бита (старшего).
3. **Рекомендация по использованию типов:**
    
    - Для предотвращения неоднозначности при сдвигах рекомендуется использовать **беззнаковые типы** (`unsigned int`).
4. **Примеры использования побитовых операций:**
    
    - **Обнуление всех бит, кроме младших трёх:**
        - Используется побитовое И с числом, у которого только три младших бита установлены в 1:
            
            ```cpp
            x & 7
            ```
            
    - **Обнуление всех бит, кроме трёх старших:**
        - Используется побитовое И с инверсией числа, у которого три младших бита установлены:
            
            ```cpp
            x & ~7
            ```
            
    - **Установка двух младших бит:**
        - Используется побитовое включающее ИЛИ с числом 3:
            
            ```cpp
            x | 3
            ```
            
    - **Установка пяти младших бит:**
        - Используется сдвиг:
            
            ```cpp
            x | ((1 << 5) - 1)
            ```
            
        - Здесь `(1 << 5)` создаёт число с установленным 6-м битом, а вычитание 1 приводит к установке первых пяти младших бит.

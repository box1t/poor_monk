### Определения из текста:

1. **Приведение типов:**  
    Автоматическое преобразование операндов к одному типу для выполнения арифметических операций или операций присваивания.
    
2. **Целочисленное расширение (integer promotion):**  
    Преобразование операндов целого типа короче, чем `int`, к типу `int` (или `unsigned int`, если значения не умещаются в `int`) для предотвращения потери точности при вычислениях.
    
3. **Ранг приведения типа:**  
    Упорядочение целых типов, определяющее, какой тип из двух операндов будет использован для приведения при различии типов. Например, `long` имеет больший ранг, чем `int`, а `int` — больший, чем `char`.

### Определения из текста:

1. **Операции с побочным эффектом:**  
    Операции, которые изменяют значение операндов, например, инкремент (`++`) и декремент (`--`), а также операции присваивания. Побочный эффект — это изменение значения операнда.
    
2. **Постфиксная и префиксная формы инкремента/декремента:**
    
    - Постфиксная форма (`a++`): сначала используется значение переменной, затем происходит её изменение.
    - Префиксная форма (`++a`): сначала значение переменной изменяется, затем используется.
3. **Операции сравнения:**  
    Операции, которые возвращают результат типа `int`: 1 (истина), если условие выполнено, и 0 (ложь), если нет.
    
4. **Операция последовательного вычисления (`,`):**  
    Вычисляет операнды слева направо, результатом является значение последнего операнда.
    
5. **Условная операция (`?:`):**  
    Оператор, который вычисляет одно из двух выражений в зависимости от значения логического условия.
    
6. **Точка следования:**  
    Момент выполнения программы, когда все побочные эффекты предыдущих вычислений завершены, а новые ещё не начаты.

---

### **Ключевые моменты:**

1. **Точки последовательных вычислений:**
    
    - Конец полного выражения (например, после вычисления всего выражения `a + b - c*d`).
    - Между вычислениями операндов в выражениях с запятой (`,`) или условной операцией (`z ? x : y`).
    - Перед выполнением тела функции и после вычисления её аргументов.
    - Между вычислениями операндов в выражениях с логическими операциями `&&` и `||`.
2. **Некорректные выражения:**
    
    - Примеры: `(a=2) + (a=3)`, `i++ + ++i`, `a = b++ + b`.
    - Нарушение семантики: переменная модифицируется более одного раза между двумя точками следования, или её старое значение используется для вычислений параллельно с модификацией.
3. **Undefined behavior (неопределённое поведение):**
    
    - Стандарт языка C не требует от компилятора определённого результата для таких выражений.
    - Разные компиляторы или разные оптимизации могут привести к различным результатам.
4. **Рекомендации:**
    
    - Не использовать выражения, которые модифицируют переменную несколько раз в одном полном выражении.
    - Соблюдать чёткий порядок вычислений и избегать неопределённого поведения.

- Каковы базовые типы языка Си?
	- char (символьный),
	- int (целый),
	- float (с плавающей точкой),
	- double (двойной точности),
	- void (без значения)

- Каковы целочисленные типы?
	- int и char

- Какие известны модификаторы типов?
	- **модификаторы знаковости** signed/unsigned
		- Если явно модификатор знаковости не указан, то целый тип int по умолчанию знаковый - signed int 
	- К типу int применимы также **модификаторы размера** short, long, long long.

- Перечисли спецификаторы и квалификаторы классов памяти
	- static
	- extern
	- квалификатор const

- const 
	- значение переменной не будет изменяться после инициализации, например, const int size = 100;

- Что произойдет при попытке изменить const?
	- При попытке изменить переменную произойдет ошибка на этапе компиляции.

- static
	- место под переменную будет выделено в статической памяти, доступ к переменной возможен во время всего выполнения программы

- Когда инициализируется static?
	-  инициализация static-переменной выполняется до начала работы программы.

- extern
	- место под глобальную переменную выделяется при ее объявлении в другом файле, инициализация также выполняется в другом файле.

- Можно ли получить доступ к extern-переменной во время работы программы?
	- Да, доступ к переменной возможен во время всего выполнения программы.


- Что стоит слева и справа от оператора присваивания?
	- Левая часть присваивания должна обозначать объект памяти
	- правая - является выражением

- Что есть результат присваивания?
	- Результатом присваивания является изменение объекта памяти.
	- присваивание является операцией и генерирует значение – результатом присваивания является значение левой части.
	- операция присваивания ассоциируется справа налево. т.е. сначала вычисляется выражение справа, его результат записывается в переменную слева, и так до конца всех переменных этой цепочки присваивания.

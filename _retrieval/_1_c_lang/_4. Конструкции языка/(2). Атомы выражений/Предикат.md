

### 1. Что такое "предикат" в языке Си?

В языке C предикатом называют функцию (или выражение), которая возвращает булево значение (`true` или `false`). В C нет встроенного `bool`, но с C99 появился `#include <stdbool.h>`, определяющий `true` и `false` как `1` и `0`.

**Пример предиката:**

```c
#include <stdbool.h>
#include <stdio.h>

bool is_even(int n) {
    return (n % 2 == 0);
}

int main() {
    int num = 4;
    if (is_even(num)) {
        printf("Число четное\n");
    } else {
        printf("Число нечетное\n");
    }
    return 0;
}
```

### 2. Методы и сигнатуры предикатов в C

Предикат в C может быть реализован разными способами:

1. **Функция, возвращающая `bool` (C99+)**
    
    ```c
    bool is_positive(int x) {
        return x > 0;
    }
    ```
    
2. **Функция, возвращающая `int` (до C99)**
    
    ```c
    int is_positive(int x) {
        return x > 0;
    }
    ```
    
    (здесь 0 интерпретируется как `false`, а ненулевые значения как `true`)
    
3. **Макрос для предикатов (использование `#define`)**
    
    ```c
    #define IS_POSITIVE(x) ((x) > 0)
    ```
    
    Такой макрос быстрее, но может привести к проблемам с побочными эффектами.
    
4. **Указатели на предикат-функции**
    
    ```c
    typedef bool (*Predicate)(int);
    bool greater_than_five(int x) {
        return x > 5;
    }
    ```
    
    Указатели на функции позволяют передавать предикаты в другие функции.
    

### 3. Связанные термины

- **Predicate function** – функция-предикат
- **Higher-order functions** – функции, принимающие предикаты
- **Filter functions** – фильтрация с использованием предикатов
- **Lambda expressions** (в C нет, но можно эмулировать через макросы)
- **Short-circuit evaluation** – ленивое вычисление выражений `&&` и `||`

### 4. Какой подход отражает?

Предикаты применяются в C для:

- Фильтрации массивов (например, `qsort` использует предикат)
- Поиска элементов (использование `bsearch`)
- Реализации структур функционального программирования
- Проверки условий в `assert()` и других конструкциях

### 6. Сравнение с аналогами в других языках

- **C++** – Использует `std::function<bool(T)>`, лямбда-выражения
- **Python** – Функции `filter()`, `map()`, `lambda`
- **Java** – `Predicate<T>` из `java.util.function`
- **Haskell** – Чисто функциональный стиль: `filter (\x -> x > 0) [1,2,3,-1]`

### 7. Примеры использования

#### Фильтрация массива (имитация `filter` в C)

```c
#include <stdio.h>
#include <stdbool.h>

#define SIZE 5

bool is_positive(int x) {
    return x > 0;
}

void filter(int* arr, int size, bool (*predicate)(int)) {
    for (int i = 0; i < size; i++) {
        if (predicate(arr[i])) {
            printf("%d ", arr[i]);
        }
    }
    printf("\n");
}

int main() {
    int numbers[SIZE] = {1, -2, 3, -4, 5};
    filter(numbers, SIZE, is_positive);
    return 0;
}
```

**Выход:** `1 3 5`

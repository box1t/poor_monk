## 1. Программа, алгоритм, код. Свойства алгоритма.

- `Алгоритм` 
	- точно заданный (недвусмысленный) порядок выполнения (последовательность) конечного числа шагов, ведущий к результату.

- Алгоритм (способы представления)
	- Псевдокод - абстрактное описание алгоритма
	- Код - точное представление алгоритма для исполнения на компьютере
	- etc

- Свойства алгоритма
	- Массовость - универсальность, применимость к многим задачам одного типа
	- Детерминированность - однозначность трактовки, предсказуемость работы
	- Элементарность каждого шага - исключение неопределенности.
	- Результативность - число шагов конечно, что делает алгоритм полезным.
	- Сложность - эффективность по времени и используемой памяти.

- `Пространственная сложность` 
	- объём памяти, необходимый алгоритму для обработки сообщения длины n.
	- **память** - ***пространство*** данных
	- **сложность** - ***зависимость*** (функция)

- `Операнд` 
	- аргумент операции; данные, которые обрабатываются командой (a+b, ‘a’ и ‘b’ — операнды).

- `Предикат` 
	- логическое высказывание, функция на множестве отношений {И,Л}. 

- **Формальный алгоритм:** 
	- Чётко определённая последовательность действий, которая приводит к решению задачи. Он строго формализован, без двусмысленностей.

- **Неформальный алгоритм:** 
	- Описание последовательности действий без строгой формализации, часто словами.
	- Это всё же алгоритм. В нем нет двусмысленности, но выражен он так, чтобы быть понятным человеку, с соблюдением чёткости шагов.

- Псевдокод
	- это промежуточный шаг между неформальным описанием и формализацией. Он ещё содержит абстракции, понятные человеку, но их можно строго интерпретировать.

- **Эвристика:** 
	- Приближённый способ решения, который не гарантирует результата, но позволяет найти ответ быстрее или проще. Пример: правила "по опыту" без полного доказательства.

- Программа
	- алгоритм, реализованный через код, который можно запустить и выполнить.
	- исполнимый алгоритм на основе кода.
	- Программа – это размещённые в оперативной памяти компьютера данные и машинные инструкции, исполняемые процессором для достижения некоторой цели

- Связь кода и алгоритма
	- Алгоритм — это абстрактная последовательность действий. 
	- Код — это конкретная запись алгоритма на языке программирования.  

- Связь кода и программы
	- Код — это основная (?) часть программы. 
	- Код — это инструкция для машины, а программа — её исполнение в полном контексте.

- Связь алгоритма и программы
	- Код это конкретная реализация алгоритма, являющаяся частью программы.

- Составляющие программы
	- код, 
	- данные, 
	- настройки, 
	- интерфейс. 

- Что делать с кодом, а что с программой?
	- **С программой:** Запускать, тестировать, использовать, настраивать.
	- **С кодом:** Читать, писать, редактировать, компилировать или интерпретировать, анализировать.

- Отличие запуска кода от запуска программы
	- **Запуск кода:** Обычно через интерпретатор или компилятор (например, `python script.py`).
	- **Запуск программы:** Это исполнение собранного/компилированного кода, часто через пользовательский интерфейс (например, клик по иконке).



- **Бинарник** 
	- это **скомпилированная версия программы**, которая уже представлена в машинном (бинарном) коде. Она содержит инструкции, понятные процессору.
	- Компилятор переводит код в бинарный формат, который состоит из инструкций для процессора.
	- Программа уже может включать в себя бинарник.

- Отличие бинарного кода от кода
	- Код читаем человеком, бинарник читаем машиной.
    - Код редактируем и понятен программистам, а бинарник — это уже исполняемый файл (например, `.exe` или `.bin`), который нельзя напрямую редактировать.

Задание №2:
Наберите нужную сумму минимальным количеством монет. Требуемая сумма гарантированно влезает в int. Набор монет задан, достоинство может быть различным (допустим, их собрали со всех времен и эпох), но гарантируется, что жадный алгоритм на этом наборе сработает.

#include <iostream>
using std:: cin;
using std:: cout;
using std:: endl;
int main ()
{
    int n, a[1000]={0};
    cin>>n;
    //введение массива
    for (int i=0; i<n; i++)
    {
        cin>>a[i];
    }
   //сортировка массива
   for (int c=0; c<n; c++)
    {
        for (int i=0; i<n-c-1; i++)
    {
        if (a[i]<a[i+1])
        {
            int b=a[i];
            a[i]=a[i+1];
            a[i+1]=b;
        }
    }
    }
    int x;
    cin>>x;
    int sum=0, I=0, N=0;
    while (sum<=x)
    {
      if (I<n)
      {
          if (sum+a[I]<=x)
          {
              sum=sum+a[I];
              I=I+1;
              N=N+1;
          }
          else I=I+1;
      }
      else break;
    }
    if (N>0&&sum==x)
    {
        cout<<N<<endl;
    }
    else cout<<"-1"<<endl;
    return (0);
}

Задание №4:
Напишите функцию, которая находит в отсортированном массиве элемент с нужным значением, и возвращает его индекс. Гарантируется, что такой элемент, если он существует, ровно один. Используйте бинарный поиск. Даже если решение с полным перебором всех элементов по порядку укладывается по время и проходит тесты - этот контест не на оценку, поэтому почему бы не потренироваться?
int search_rec(int x, int* array, int n);
int search_rec(int x, int* array, int n)
{
    int A[100];
    for (int i = 0; i < n; i++)
        {
            A[i] = *(array + i);
        }
    int mid= n/2, d = 0, c = n;
    for (int i = 0; i < n; i++)
        {
            if (A[mid] == x) return mid;
            else if (A[mid] > x)
            {
                c = mid; mid = (mid - d) / 2;
            }
            else if (A[mid] < x)
                {
                    d = mid; mid = mid + (c - mid) / 2;
                }
        }
    return -1;
}

Задание №5:
По Тамриэлю проходит длинный торговый путь, который занимает несколько дней. На торговом пути равномерно располагаются точки отдыха - придорожные таверны и трактиры, каждая из которых устанавливает свою стоимость ночевки. Жадный хаджит ведет по этому пути свой караван, нагруженный ценными товарами. Он не хочет ночевать на улице, но и платить лишнего тоже не собирается. За дневной переход он может доехать от одной точки отдыха до следующей - или, если будет быстрее перебирать лапками, до послеследующей. Дальше уже не успевает. Каждое утро он смотрит на карту и принимает локально жадное решение: если в следующей точке ночевка не дороже, чем в послеследующей, то он идет туда. Если в послеследующей дешевле, то туда. Маршрут он заранее не планирует и, разумеется, его траты не являются оптимальными. Но вразумлять глупого хаджита мы будем в других сериях, а пока что посчитайте, сколько дрейков он потратит, руководствуясь своими нехитрыми принципами.
Разберем один случай. Вначале жадный хаджит смотрит на первые два пункта. В первом дороже, поэтому он идет в следующий. Платит 1 дрейк, ночует. Утром он смотрит на следующие два. Пять меньше десяти, поэтому он идет в следующую точку отдыха. Платит 5 дрейков (итого 6), ночует. Утром смотрит и видит, что ему предстоит нелегкий день - идти на послеследующую точку. Доходит, платит 1 дрейк (итого 7), ночует. Утром, проклиная Акатоша, он снова пускается в дальнюю дорогу (8 > 3). Доходит, платит 3 дрейка (итого 10), мгновенно засыпает. Наутро он видит, что и следующий, и послеследующий пункты стоят по 1 дрейку. Так как наш жадный хаджит еще и немного ленив, то он идет в следующую. Платит 1 дрейк (итого 11), ночует. Утром он видит два вариант - 1 и 10 дрейков, идет в тот, где 1. Платит (итого 12), ночует. Утром он видит, что может поднажать и закончить путешествие, чем успешно и занимается. Таким образом, на данном торговом пути со своим алгоритмом он потратил 12 дрейков. Нетрудно видеть, что один дрейк он мог бы и сэкономить (не заходить в предпоследнюю гостиницу), но наш хаджит жаден, недальновиден и уперт. И немного ленив.

#include <iostream>
using std:: cin;
using std:: cout;
using std:: endl;
int main ()
{
    int n, a[1000]={0};
    cin>>n;
    //введение массива
    for (int i=0; i<n; i++)
    {
        cin>>a[i];
    }
    a[n]=0;
    a[n+1]=0;
    int summ=0;
    for (int i=-1;i<n;)
    {
        if (a[i+1]<=a[i+2])
        {
           summ=summ+a[i+1];
           i=i+1;
        }
        else
        {
            summ=summ+a[i+2];
            i=i+2;
        }
    }
    cout<<summ<<endl;
    return 0;
}

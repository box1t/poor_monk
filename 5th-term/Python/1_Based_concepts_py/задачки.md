- что такое pyobject с точки зрения C
	- каждый объект имеет идентичность, тип, значение
	- id никогда не меняется после создания объекта (is сравнивает id объектов)
	- Тип объекта определяет какие операции с ним можно выполнять
	- Значение объекта может меняться

```c
typedef struct _object {
	_PyObject_HEAD_EXTRA
	Py_ssize_t ob_refcnt;
	PyTypeObject *ob_type;
} PyObject;
```

### 📌 **Функции в языке C**

- Функция в языке C 
	- это именованный блок кода для выполнения определённой задачи. 
	- позволяет структурировать программу, повышая её читаемость, повторное использование кода и поддержку.

- Адрес функции 
	- – это адрес машинной инструкции, с которой должно начинаться её выполнение

---

## 🔹 **1. Для чего в C нужна функция?**

1. **Разделение кода на логические части** — увеличивает читаемость и упрощает поддержку.
2. **Повторное использование кода** — предотвращает дублирование логики.
3. **Инкапсуляция и абстракция** — скрывает детали реализации.
4. **Разделение области видимости переменных** — помогает управлять памятью.
5. **Уменьшение ошибок** — если код работает в одном месте, он работает везде.

---

## 🔹 **2. Методы объявления и сигнатуры функций в C**

### **Стандартное объявление функции**

```c
return_type function_name(parameter_list);
```

Где:

- `return_type` — тип возвращаемого значения (например, `int`, `void`, `double`).
- `function_name` — имя функции.
- `parameter_list` — список параметров (их типы и имена).

---

### **Виды функций и сигнатур в C**

#### ✅ **1. Функция без аргументов и без возвращаемого значения (`void`)**

```c
void sayHello() {
    printf("Hello, World!\n");
}
```

- **Используется для побочных эффектов (вывод, изменение глобальных переменных).**
- **Нет возвращаемого значения.**
- **Вызывается просто как `sayHello();`.**

---

#### ✅ **2. Функция без аргументов, но с возвращаемым значением**

```c
int getNumber() {
    return 42;
}
```

- **Не принимает параметры.**
- **Возвращает `int`.**
- **Вызывается как `int x = getNumber();`.**

---

#### ✅ **3. Функция с аргументами и возвращаемым значением**

```c
int add(int a, int b) {
    return a + b;
}
```

- **Принимает два `int` параметра.**
- **Возвращает сумму `int`.**
- **Вызывается как `int sum = add(3, 4);`.**

---

#### ✅ **4. Функция с массивом (передача по указателю)**

```c
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++)
        printf("%d ", arr[i]);
}
```

- **Массив передаётся как указатель (`int arr[] ≡ int* arr`).**
- **Нужно передавать его размер явно.**
- **Вызывается как `printArray(arr, 5);`.**

---

#### ✅ **5. Функция с указателями (изменение аргумента)**

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

- **Использует указатели, чтобы менять переменные в вызывающем коде.**
- **Вызывается как `swap(&x, &y);`.**

---

#### ✅ **6. Функция с переменным числом аргументов (`stdarg.h`)**

```c
#include <stdarg.h>
#include <stdio.h>

void printNumbers(int count, ...) {
    va_list args;
    va_start(args, count);
    for (int i = 0; i < count; i++)
        printf("%d ", va_arg(args, int));
    va_end(args);
}
```

- **Используется `stdarg.h`.**
- **Вызывается как `printNumbers(3, 1, 2, 3);`.**

---

## 🔹 **3. Ключевые термины, связанные с функциями**

| Термин                    | Описание                                       |
| ------------------------- | ---------------------------------------------- |
| **Прототип функции**      | Объявление функции до её определения.          |
| **Стек вызовов**          | Хранит адрес возврата и локальные переменные.  |
| **Передача по значению**  | Аргументы передаются копированием.             |
| **Передача по указателю** | Функция изменяет оригинальную переменную.      |
| **Рекурсия**              | Функция вызывает саму себя.                    |
| **Inline-функция**        | Оптимизация компилятором для встраивания кода. |
| **Функция-указатель**     | Позволяет передавать функции как аргументы.    |

---

## 🔹 **4. Глубокие технические особенности**

6. **Функции хранятся в секции `.text` памяти** (неизменяемой).
7. **Аргументы передаются через стек или регистры** (в зависимости от архитектуры).
8. **Переполнение стека (`stack overflow`)** возможно при глубокой рекурсии.
9. **Передача структуры как аргумента копирует её целиком**, что может быть неэффективно.
10. **Функции-указатели** позволяют реализовывать стратегии и обратные вызовы (callback-функции).
11. **`const` параметры защищают данные от изменений внутри функции.**
12. **Inline-функции (`static inline`)** уменьшают накладные расходы на вызовы.

|**Функции в Java**|Методы классов с поддержкой ООП.|

## 🔹 **6. Примеры более сложного использования**

### **1️⃣ Указатели на функции (callback)**

```c
#include <stdio.h>

void sayHello() {
    printf("Hello!\n");
}

void executeFunction(void (*func)()) {
    func();
}

int main() {
    executeFunction(sayHello);
    return 0;
}
```

- **Передаёт функцию как аргумент.**

---

### **2️⃣ Рекурсивная функция (Факториал)**

```c
int factorial(int n) {
    return (n <= 1) ? 1 : n * factorial(n - 1);
}
```

- **Классическая рекурсия.**

---

### **3️⃣ Функция с `static` переменной**

```c
void counter() {
    static int count = 0;
    count++;
    printf("Counter: %d\n", count);
}
```

- **Переменная `count` сохраняет значение между вызовами.**

Объявления и определения функций, объявления переменных. Области видимости
переменных: глобальные и локальные переменные. Директивы препроцессора.


- Состав программы на СИ
	- Программа на языке Си состоит из объявления переменных или функций, а также определения функций 

- Где объявляются локальные переменные, а где глобальные?
	- Глобальные переменные объявляются вне определения функций 
	- локальные – внутри функции или блока операторов

- Каковы области видимости для локальной и для глобальных переменных?
	- для локальной переменной – блок или функция, в которой она объявлена 
	- для глобальной переменной – программный файл, начиная со строки объявления. 


- Как проявляется перекрытие имен?
	- если имена локальной и глобальной переменной совпадают, то в локальной области видимости используется локальная переменная


- Почему функция main типа int?
	- Выполнение программы начинается с функции main, которая имеет целочисленное возвращаемое значение. Это значение для функции main является кодом возврата программы для операционной системы, и есть договоренность, что завершившаяся успешно программа возвращает 0, а возврат ненулевого значения делается в случае ошибки.

- Какое требование к вызову функции?
	- Она должна быть объявлена в месте вызова.
	- Если она находится в другом файле, заголовочный файл с ним должен быть предварительно подключен в текущий файл.

- Для чего используется include?
	- Это директива препроцессора для вызова функций, определения которых содержатся в других программных файлах.

Задание по одномерным массивам.

1. Даны два одномерных массива чисел А и В. Сформировать из них массив С, 
который содержит нечетные элементы А, которых нет в В.

2. Даны два одномерных массива чисел А и В. 
Сформировать из них массив С, который содержит элементы А, 
которые есть в В более, чем в одном экземпляре.

3. Даны два одномерных массива А и В. 
Сформировать из них массив С, который содержит неповторяющиеся элементы А, которых нет в В.

4. Даны два одномерных массива чисел А и В.
Сформировать из них массив С, который содержит четные элементы А, которые есть в В.

5. Даны два одномерных массива чисел А и В. 
Сформировать из них массив С, который содержит элементы А по модулю равные некоторым элементам В.

6. В заданном одномерном массиве чисел А найти последний по порядку элемент, являющийся простым числом.

В тоерии новый получаемый массив С нужно записывать как односвязный список



7. Даны два одномерных массива чисел А и В. 
Сформировать из них массив С, где к каждому четному элементу А добавлено сколько раз 
этот элемент встречается в массиве В.

8. Даны два одномерных массива чисел А и В. 
Сформировать из них массив С, где после каждого элемента А вставлен ближайший 
по модулю элемент из массива В.

9. Даны два одномерных массива чисел А и В.
 Сформировать из них массив С, где к каждому четному элементу А добавить минимальный элемент из массива В, 
 а к каждому нечетному элементу А добавить максимальный элемент из В.

В заданиях, где условие неоднозначно, необходимо доопределить его логичным образом.

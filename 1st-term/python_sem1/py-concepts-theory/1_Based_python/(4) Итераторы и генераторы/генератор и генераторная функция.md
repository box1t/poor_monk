
### 2. Difference Between Generator and Generator Function
- **Generator Function**: This is a function that contains one or more `yield` expressions. When called, it returns a generator object but does not start execution immediately. Instead, execution starts when the generator's `__next__()` method is called.

  ```python
  def generator_function():
      yield 1
      yield 2
      yield 3
  ```

- **Generator**: This is the object created by calling a generator function. It conforms to the iterator protocol and generates values one at a time using the `yield` statement.

  ```python
  gen = generator_function()  # gen is a generator
  print(next(gen))  # Output: 1
  print(next(gen))  # Output: 2
  print(next(gen))  # Output: 3
  ```

В языке программирования Python различие между выражениями и утверждениями, а также понятия простых и составных утверждений, играет важную роль в понимании синтаксиса и структуры программ. Давайте рассмотрим эти концепты подробнее.

### Выражения и утверждения

**Выражение (expression):**
Выражение — это конструкция, которая вычисляется до значения. Примеры выражений включают числа, строки, арифметические операции, вызовы функций и так далее. 

Примеры выражений:
- `42`
- `3 + 5`
- `"Hello, World!"`
- `a + b`
- `max(3, 7)`

**Утверждение (statement):**
Утверждение — это конструкция, которая выполняет действие. Утверждения могут содержать выражения, но они не обязательно возвращают значение. Утверждения включают объявления переменных, управляющие структуры (такие как циклы и условные операторы), и вызовы функций, которые не возвращают значение.

Примеры утверждений:
- `x = 5`
- `print("Hello, World!")`
- `if x > 0:`
- `for i in range(10):`

### Простые и составные утверждения

**Простое утверждение (simple statement):**
Простое утверждение выполняется за один шаг. Оно не включает других утверждений внутри себя. К простым утверждениям относятся:

- Присваивание (`x = 5`)
- Вызов функции (`print("Hello, World!")`)
- Импорт модулей (`import math`)

Пример простых утверждений:
```python
x = 5
y = x + 2
print(y)
```

**Составное утверждение (compound statement):**
Составное утверждение состоит из одного или нескольких простых утверждений и включает в себя другие утверждения, образуя блоки кода. К составным утверждениям относятся:

- Условные операторы (`if`, `elif`, `else`)
- Циклы (`for`, `while`)
- Функции (`def`)
- Классы (`class`)
- Исключения (`try`, `except`, `finally`)

Пример составного утверждения:
```python
if x > 0:
    print("x is positive")
else:
    print("x is non-positive")
```

В этом примере составное утверждение `if-else` включает два простых утверждения `print`.

### Примеры

Пример выражения и утверждения:
```python
# Выражение
result = 3 + 4  # Здесь "3 + 4" - это выражение, которое вычисляется до значения 7

# Утверждение
if result > 5:  # Здесь "if" является утверждением
    print("Result is greater than 5")  # А это утверждение print
```

Пример простого и составного утверждения:
```python
# Простое утверждение
x = 10

# Составное утверждение
if x > 5:  # Условное утверждение
    print("x is greater than 5")  # Простое утверждение внутри составного
    x -= 5  # Простое утверждение внутри составного
else:
    print("x is 5 or less")  # Простое утверждение внутри составного
```

Понимание этих концептов помогает лучше структурировать код, делать его более читабельным и эффективным.

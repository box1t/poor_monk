
## debugger

### **1. Почему `int main`, а не `void`?**

- **Вопрос:** Почему `main` возвращает `int`, а не `void`?
- **Ответ:**
    - Функция `main()` является точкой входа программы, и стандарт C (ISO C) требует, чтобы она возвращала `int`.
    - Возвращаемое значение передается операционной системе и указывает на успешное (`0`) или неуспешное (`!=0`) завершение программы.
    - Использование `void main()` — это нарушение стандарта, даже если некоторые компиляторы его допускают.

### **2. Почему `main()` с круглыми скобками, а не `{}`?**

- **Вопрос:** Почему `main()` записывается с `()`, а не `{}`?
- **Ответ:**
    - Круглые скобки `()` используются для объявления и вызова функций, указывая список параметров.
    - Фигурные скобки `{}` содержат тело функции, то есть набор инструкций, которые выполняются при вызове.
    - Запись `main {}` без `()` — это синтаксическая ошибка, потому что C требует, чтобы функции определялись с `()`, даже если они не принимают параметры.

### **3. Когда в `main()` нужны входные параметры?**

- **Вопрос:** В каких случаях `main()` принимает параметры?
    
- **Ответ:**
    
    - Если программа должна получать аргументы командной строки, `main()` принимает два параметра:
        
        ```c
        int main(int argc, char *argv[])
        ```
        
    - **`argc` (argument count)** — количество аргументов (включая имя программы).
    - **`argv` (argument vector)** — массив строк с аргументами.
- **Пример:** Запуск `./prog file.txt 42` дает:
    
    ```c
    argc = 3;
    argv[0] = "./prog";    // Имя программы
    argv[1] = "file.txt";  // Первый аргумент
    argv[2] = "42";        // Второй аргумент
    ```
    
    - Входные параметры используются, например, в консольных утилитах, которые принимают аргументы (`ls -l`, `gcc main.c -o main`).

### **4. Различия статус-кодов возврата (`return 0`, `1`, `-1` и другие)**

- **Вопрос:** Как интерпретируются различные коды возврата `0`, `1`, `-1`?
    
- **Ответ:**
    
    - `return 0;` → Успешное завершение программы.
    - `return 1;` → Ошибка выполнения (в POSIX и UNIX используется как общий код ошибки).
    - `return -1;` → Часто используется для специфических ошибок (например, если системный вызов завершился с ошибкой).
    - **Другие коды**:
        - В POSIX-кодах (`<stdlib.h>`) есть `EXIT_SUCCESS` (`0`) и `EXIT_FAILURE` (`1` или `-1`).
        - В Windows есть дополнительные коды (`GetExitCodeProcess`).
- **Нужно ли всегда писать `return`?**
    
    - Если `main()` объявлен как `int`, но нет `return`, поведение не определено в старых версиях C.
    - В C99+ компилятор автоматически вставит `return 0;`, если программа дошла до конца.

### **5. За что отвечают операторы `>>` и `<<`?**

- **Вопрос:** Что делают операторы `>>` и `<<`?
    
- **Ответ:**
    
    - В C++ (`iostream`) они используются для потокового ввода-вывода:
        
        ```cpp
        int x;
        std::cin >> x;   // Ввод
        std::cout << x;  // Вывод
        ```
        
    - В C (и C++) они используются как побитовые операторы:
        
        ```c
        int a = 8; // 1000 в двоичной системе
        int b = a << 1; // 16 (10000) - сдвиг влево
        int c = a >> 1; // 4 (0100) - сдвиг вправо
        ```
        
- **Различие в побитовых операциях:**
    
    - `x << n` → Сдвигает `x` влево на `n` битов (умножение на `2^n`).
    - `x >> n` → Сдвигает `x` вправо на `n` битов (деление на `2^n`, с учетом знака).
    - Используется в битовой маске, шифровании, алгоритмах сжатия данных.

### **6. Как и зачем использовать дебаггер?**

- **Вопрос:** Как использовать дебаггер и зачем он нужен?
    
- **Ответ:**
    
    - Дебаггер (`gdb`, `lldb`, `Visual Studio Debugger`) позволяет:
        - Запускать программу пошагово (`step`, `next`).
        - Просматривать значения переменных (`print var`).
        - Устанавливать точки останова (`break main`).
        - Анализировать причину аварийного завершения (`bt`, `info locals`).
- **Пример с циклами и ветвлениями:**
    
    ```c
    #include <stdio.h>
    
    int main() {
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            sum += i;
            if (sum > 6) {
                printf("Сумма превысила 6: %d\n", sum);
            }
        }
        return 0;
    }
    ```
    
    - Можно поставить точку останова (`break main`), выполнить `step`, посмотреть переменные (`print sum`), проверить условие (`watch sum > 6`).

### **7. Верно ли, что дебаггер позволяет задать критерий останова?**

- **Вопрос:** Дебаггер позволяет задать критерий останова или он вспомогательный?
- **Ответ:**
    - **Да**, можно задать критерий останова (breakpoint):
        - `break main` — остановка при входе в `main`.
        - `break filename.c:10` — остановка на 10-й строке.
        - `watch sum > 6` — остановка, если `sum > 6`.
    - **Критерий останова** можно использовать не только для отслеживания прогресса, но и для автоматического прерывания выполнения при подозрительных значениях переменных.

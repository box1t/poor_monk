## Статические члены не связаны с объектами класса

Статические члены существуют, даже если объекты класса не созданы! 
Они создаются при запуске программы и уничтожаются, когда программа завершает свое выполнение.

Статические члены принадлежат классу, а не объектам этого класса. 

Поскольку `s_value` существует независимо от любых объектов класса, то доступ к нему осуществляется напрямую через имя класса и оператор разрешения области видимости (в данном случае, через `Anything::s_value`):


```c++
#include <iostream>
class MyClass {
public:
	static int s_value; // объявляем статическую переменную-член
};

int MyClass::s_value = 3; // определяем ее

int main() {

// здесь мы не создаем никаких объектов класса MyClass

	MyClass::value = 5;
	std::cout << MyClass::value;
	return 0;
}
```

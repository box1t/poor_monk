Существуют три модификатора доступа:
private, public, protected.

Эти модификаторы разграничивают доступ к полям методов класса (и структур)

```c++
class C{
public:
	int a;
protected:
	int b;
private:
	int c;
};
```

Все, что пишется до следующего модификатора или до конца класса, будет текущего модификатора доступа.

К публичному полю доступ имеют все. 
К приватному полю имеет доступ объект класса и друзья класса.
Протектед поле работает как приватное, но пока мы не прошли наследование.


Проверка доступа происходит на этапе компиляции (иначе не скомилируется) и после выбора перегрузки.

Друг может объявляться к приватным методам.

Дружба это ориентированный граф - направлен в обе стороны.
Но не транзитивный - дружба не передается от А к С.

Конструктор - специальный метод класса, в котором описано, как создать объект от данных параметров. 

Конструкторы используются для инициализации полей объекта. Это можно сделать, передав в конструктор аргументы, и, написав в теле конструктора код, вычисляющий значения полей. Для полей, которые не были проинициализированы, вызывается конструктор по умолчанию (конструктор без аргументов), а для примитивных типов конструктор не вызывается, и такие поля имеют произвольные значения.


- конструктор по умолчанию - не принимает аргументов. вызывается при создании объектов без указания аргументов
- конструктор с параметрами - принимает аргументы и инициализирует их 
- копирования - принимает ссылки на объект того же класса в качестве аргумента, создает новый объект как копию существующего
- перемещения - принимает рвалью ссылку на объект того же класса. используется для перемещения ресурсов из одного объекта в другой

Список инициализации конструктора позволяет передать аргументы каждому из прямых базовых классов, однако порядок выполнения конструкторов (constructor order) зависит от порядка их расположения в списке наследования класса. Порядок их расположения в списке инициализации конструктора не имеет значения.

##### Когда вызываются конструкторы и деструкторы

Конструктор класса вызывается в момент его создания. Пока конструктор класса не отработает, объектом пользоваться нельзя.

Деструктор класса вызывается, когда объект покидает свою область видимости.

Порядок вызова конструкторов:

1. сначала базовый класс
2. потом члены в порядке их объявления
3. потом конструктор самого класса

Порядок вызова деструкторов:
- обратно порядку вызова конструкторов

# explicit

Copy constructor

```c++
class Vector {
public:
	explicit Vector(size_t size, int value = 0) : arr_(new int[size]), size_(size)  {
	memset(arr_ value, size);
	}
};

int main() {
	Vector v = 10; // Вектор равен числу? НЕТ.
// Здесь происходит неявное приведение типа int к size_t, а из size_t создается вектор. Чтобы запретить такие действия, добавим ключевое слово explicit.

// explicit запрещает неявное приведение типов в конструкторе
```

# delete

Компилятор умеет генерировать некоторые методы сам.
Нам хочется запретить ему делать это.

Например, не хотим, чтобы метод умел копироваться.

delete - запретить

```c++

struct S{

// 2. Допустим, завели конструктор от int a.
// Теперь у нас нет конструктора по умолчанию.
// Я хочу, чтобы компилятор его сгенерировал. Мне лень писать.
// Поэтому я напишу следующее:
	S() = default;
	S(int a){}
	S(const S&) = delete; 
	// 1. это запрещает компилятору генерировать некоторые методы автоматически

	~S() = delete;
	// Если запретим генерировать деструктор, 
	// компилятор откажется создавать объект данного класса

};

```




### default

Суть его заключается в том, что пользователь может указать компилятору реализовать ту или иную функцию-член класса по-умолчанию.

```
class Foo
{
public:
    Foo(int x) {/* ... */}
}
```

Необходимо реализовать конструкор по умолчанию. Вместо определения конструктора без параметров, в C++11 появилась возможность просто указать компилятору сгенерировать его по-умолчанию. Достигается это, как я сказал выше, при помощи спецификатора default.

```
class Foo
{
public:
    Foo() = default;
    Foo(int x) {/* ... */}
};
```

# Task3. Передача аргументов в функцию

```c++
##### Передача аргументов в функцию

По значению:

void f(int n)
{
    ++n;
    std::clog << n << std::endl;
}

x = 3;
f(x);  // 4
std::cout << x << std::endl;  // 3

По ссылке:

void f(int& n)
{
    n = n + 1;
    std::clog << n << std::endl;
}

x = 3;
f(x);  // 4
std::cout << x << std::endl;  // 4

Вариант - по константной ссылке:

void f(const int& n)
{
    n = n + 1;  // COMPILER ERROR!
    std::clog << n << std::endl;
}

x = 3;
f(x);
std::cout << x << std::endl;
```



```c++
В каком случае лучше передавать по значению, а когда по ссылке?

- дешёвые для копирования объекты - по значению
- дорогие для копирования объекты - по ссылке

Рассмотрим разницу:

std::string get_full_name(const std::string& name, const std::string& surname)
{
    return name + " " + surname;
}

std::string get_full_name(std::string name, std::string surname)
{
    return name + " " + surname;
}

А если так, в чём проблема?

std::string get_full_name(std::string& name, std::string& surname)
{
    return name + " " + surname;
}

А что происходит здесь?

std::string get_full_name(std::string *name, std::string *surname)
{
    return *name + " " + *surname;
}
```

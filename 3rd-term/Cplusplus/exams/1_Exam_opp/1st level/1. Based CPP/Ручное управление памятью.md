стек работает как детская пирамидка.
внизу лежат данные, которые мы положили первыми.

последние положенные данные первыми снимаются со стека.

```c++

	int a;

a
b

10
```

Когда мы вызываем функцию, действует соглашение о вызовах.
Оно рассказывает, куда кладутся аргументы функции.

```c++
int main() {
	T* ptr = new(...); // syntax of NEW
}
```

```c++
int main() {
	T* ptr = new int(100);
	std::cout << *ptr; // 100 output
	delete ptr; // удаляем всегда указатель
	delete ptr; // double free. mistake!!!!
}
```

new запрашивает кусок оперативки.
а вызов массива int a[100]; - запрос кусочка стека

```c++
int main() {
	int* ptr = new int(100);
	delete ptr;

	ptr = new int(123);
	delete ptr;
}
```

```c++
int main() {
	int* ptr = new int[100];

	for (int i = 0; i < 10; ++i) {
		*(ptr + i) = 0;
		ptr[i] = 0;
		// ptr[i] == *(ptr + i)
		// i[ptr] == *(i + ptr)
	}
}
```

```c++
Массивы нельзя присваивать друг другу

int a[100];
int b[100];

a = b; // НЕЛЬЗЯ

это не указатели.
это массивы. там 100 элементов.
вот в чем отличие.
указатели можно присваивать друг другу.
массивы нельзя.

массив работает как локальная переменная. они сами убираются со стека.
их не надо очищать через delete
```

Сигнатура функции - это ее название, набор принимаемых параметров и тип.


```
Адрес в RAM-модели памяти - это расстояние от начала памяти до начала этого объекта в памяти. 

Тип адреса - указатель.
NULL - макрос.
Его тип - void* 
nullptr - тип nullptr_t
0 - тип int

Изначально указатели всегда указывали внутрь массивов, поэтому поддерживается синтаксис p[2] == **(p + 2)

(2[p] = p[2] из-за коммутативности)

Инкапсуляция (private) помогает сохранить инвариант класса.
Модификаторы private-public не имеют отношения к сокрытию данных, но к сокрытию имен.

Инкапсуляция имеет отношение к двум вещам 
- к типам
- к именам
Мы можем использовать имена внутри методов типа.

```

# Шаблоны классов и функций
Для решения проблем дублирования кода придуманы шаблоны:

Шаблоны функций предоставляют функциональное поведение, которое мо­
жет быть вызвано для разных типов. 

Ключевое слово typename задает параметр типа.


## Шаблоны C++

позволяют составить один обобщнный алгоритм для различных типов данных. 

Пример шаблонной функции:

```
template<class T>
T _min(T a, T b){
    if( a < b){
        return a;
    }
    return b;
}
```

### Инстанциирование

Шаблон класса сам по себе не является ни типом, ни объектом. 

Чтобы компилятор сгенерировал код, данный шаблон должен быть инстанцирован - совершена подстановка типа.

Инстанцирование шаблона представляет собой процесс создания обычных
классов или функций путем замены параметров шаблонов конкретными ар­
гументами. 

Процесс замены параметров шаблона конкретными типами называется ин­
станцированием шаблона (instantiation). Его результатом является экземпляр
(instance) шаблона5.


# Специализация шаблонов

Идея специализации:
шаблон класса может быть специализирован, то есть частный случай для конкретного типа может быть указан непосредственно.

```c++
template <typename T> struct S {
	void dump() { std::cout << "for all\n"; }
};

// Сожрали тип Т для специализации
template<> struct S<int> { // в скобках указали, какой тип имели в виду
	void dump() { std::cout << "for int\n"; } 
};

S<int> s1; s1.dump(); // ваша специализация
S<double> s2; s2.dump(); // специализацию делает компилятор
```




В некоторых случаях шаблон функции неэффективен для определенного типа. 
Тогда можно специализировать шаблон, — написать реализацию для данного типа. 

При этом тип, для которого уточняется шаблон в параметре не указывается. 
Ниже приводится пример указанной специализации.

```
template<>
std::string _min(std::string a, std::string b){
    if(a.size() < b.size()){
        return a;
    }
    return b;
}
```

# 2.5. Специализации шаблонов классов

спе­циализированные шаблоны классов позволяют оптимизировать реализации для конкретных типов или корректировать неверное поведение определенных типов при инстанцировании шаблона класса. Однако при специализации шабло­на класса необходимо специализировать все его функции-члены. Хотя можно
специализировать и отдельную функцию-член шаблона класса, но если сделать это, то потом нельзя будет специализировать целый шаблон класса, которому принадлежит специализированный член.
Чтобы специализировать шаблон класса, следует объявить класс с предваря­ющей конструкцией template и указать типы, для которых специализируется шаблон класса. Типы используются в качестве аргументов шаблона и должны за­ даваться непосредственно после имени класса


```c++
#include "stack1.hpp"
#include <deque>
#include <string>
#include <cassert>

template<>
class Stack<std::string>
{
private:
	std::deque<std::string> elems;
public:
	void push(std::string const&);
	void pop();
	std::string const& top() const;
	bool empty() const 
	{
		return elems.empty();
	}
};

void Stack<std::string>::push(std::string const& elem)
{
	elems.push_back(elem);
}
void Stack<std::string>::pop()
{
	assert(!elems.empty());
	elems.pop_back();
}
std::string const& Stack<std::string>::top() const
{
	assert(!elems.empty());
	return elems.back();
}
```

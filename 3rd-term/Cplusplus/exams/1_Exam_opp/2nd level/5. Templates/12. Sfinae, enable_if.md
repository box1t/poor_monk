# Шаблоны классов и функций.
Термин шаблон класса (class template) означает, что класс является шабло­ном. 
Это параметризованное описание семейства классов.

Инстанцирование - процесс создания определения для обычного класса подстановкой аргументов в качестве параметров шаблона.



```c++
template <typename T1, typename T2> // Первичный шаблон класса
class MyClass {};

template <> // Явная специализация
class MyClass <std::string, float> {};

template <typename T> // частичная специализация
class MyClass <T, T> {};

template <typename T>
class MyClass <bool, T>{};

```

# SFINAE
Принцип SFINAE обеспечивает выбор между ре­ализациями шаблона функции для разных типов или ограничений.


SFINAE = Substitution Failure Is Not An Error

SFINAE - ovreloads resolution правило при наличии шаблонов: если не получается провести подстановку / сделать вывод шаблонных параметров, не генерировать ошибку компиляции, а продолжить искать другую подходящую перегрузку

Если речь идёт про SFINAE, то должны участвовать:

- шаблоны
- перегрузки
- поиск нужной перегрузки

Необходимые отступления:

- _substitution_ происходит в аргументах функции, возвращаемом типе и параметрах шаблона
    
    template HERE>
    HERE my_function(HERE x, HERE y)
    { ...; }
    
- _substitution failure_ - ситуация, когда в результате подстановки в HERE получается ill-formed выражение
    
    - если ill-formed случился не в местах подстановки, а, например, в теле функции после подстановки, то это не случай SFINAE, а обычный hard error
    - если ill-formed случился как side-effect подстановки, то это тоже hard error (что считать side-effect-ом, что точно является sfinae error - подробнее читайте документацию):


`SFINAE` - техника выбора более оптимизированной реализации на этапе компиляции по типу, пример с `my_swap` (шаблоны + перегрузки)



```c++
template <typename T, unsigned N>
std::size_t len(T(&)[N])
{
	return N;
}

// Количество элементов для типа, имеющего член size_type:
template <typename T>
typename T::size_type len(T const& t)
{
	return t.size();
}
Определяем два шаблона  1еп (), получающих один обоб­щенный аргумент.

```





# std::enable_if
std: : enable_if<> позволяет игнорировать шаблоны функций при
определенных условиях времени компиляции.

```c++
#include <iostream>

#include <type_traits>

  

// Шаблонная функция, которая доступна только для целочисленных типов

template <typename T, typename std::enable_if<std::is_integral<T>::value, int>::type = 0>

void printValue(T value) {

std::cout << "Value: " << value << std::endl;

}

  

int main() {

printValue(10); // Вызывает функцию printValue для целочисленных типов

// printValue("Hello"); // Ошибка компиляции, строковый тип не является целочисленным

return 0;

}
```
std: : enable_if<> это свойство типа, которое вычисля­ет заданное выражение времени компиляции, переданное в качестве его аргумента шаблона.

Если выражение вычисляется как true, член-тип type дает тип:
- void, если второй аргумент не передан;
- в противном случае — второй аргумент шаблона.


- Используя std: : enable_if<>, вы можете избежать проблемы, когда ша­
блоны конструкторов или операторов присваивания, которые могут быть
вызваны для одного аргумента, обеспечивают лучшее соответствие, чем не­
явно генерируемые специальные функции-члены.




# Type traits

Стандартная библиотека предоставляет различные утилиты, именуемые свой­
ствами типов (type traits), которые позволяют нам вычислять и изменять типы.
Они обеспечивают поддержку различных случаев, когда обобщенный код дол­
жен адаптироваться к различным типам, или реагировать на возможности типов,
для которых он инстанцируется. Например


```c++
#include <type_traits>
template <typename T>
class C
{
	// T is not void
	static_assert(!std::is_same_v<std::remove_cv_t<T>, void>, "Wrong instance");
public:
	template<typename V>
	void f(V&& v) 
	{
		if constexpr(std::is_reference_v<T>) {} // если Т - ссылочный тип
		if constexpr(std::is_convertible_v<std::decay_t<V>, T>) {} // если V преобразуем в Т
		if constexpr(std::has_virtual_destructor_v<T>) {} // если у V виртуальный дестр
	}
};

Как показывает этот пример, путем проверки некоторых условий мы мо­
жем выбирать между различными реализациями шаблона.
```


```c++

template <typename T>
void f(T x) {}
int main() {
    int x = 0; int& y = x; const int& z = y;
    f(x); f(y); f(z);
}
    
```

Этот код скомпилируется успешно. При вызове функции `f` из функции `main` параметр `x`, `y` и `z` передаются по значению. Важно отметить, что в C++ ссылки обрабатываются как значения и передаются по значению, а не по адресу, как указатели.

При вызове `f(x)`, `T` будет выводиться как `int`, так как `x` имеет тип `int`.
При вызове `f(y)`, `T` также будет выводиться как `int`, так как `y` - это ссылка на `int`.
При вызове `f(z)`, `T` снова будет выводиться как `int`, так как `z` - это ссылка на константный `int`.

Таким образом, все вызовы `f(x)`, `f(y)` и `f(z)` будут работать корректно, и компилятор сможет сгенерировать код для каждого вызова функции `f`.


**

Граф – это совокупность непустого множества вершин и множества пар вершин (дуг (для неориентированного) или ребер). 2 вершины называются смежными, если в графе есть дуга (ребро), соединяющая эти вершины. Граф представляется в виде матрицы смежности.

Для представления графа можно воспользоваться одномерным массивом целых чисел.

Граф с k вершинами можно представить целочисленным массивом из k столбцов и m строк, где m – максимальное число вершин, смежных с произвольной вершиной графа. Элементы столбца матрицы содержат номера смежных вершин. Этот способ удобен, когда у большинства вершин графа одинаковое или почти одинаковое число смежных вершин.

Если граф меняется в процессе обработки, то есть добавляются или удаляются вершины, то удобно использовать списки.

Способы обработки графов (алгоритмы на графах):

1)      Поиск в глубину (особенность в том, что перед тем, как перейти в новую вершину, осуществляется проверка на то, были ли мы уже в ней. Это делается для того, чтобы алгоритм не зациклился).

2)      Поиск в ширину (представляет собой алгоритм поиска кратчайшего пути из a в b). Известен, как фронт волны в дискре.

##  Поиск в ширину

```c++

#include <iostream>
#include <list>
#include <queue>
#include <algorithm>

const int MAX = 5;

std:::ostream& operator<<(std::ostream& s, std::list<int> p)
{
	for(std::list<int>::iterator i = p.begin(); i != p.end(); i++)
		s << *i << "__";
	return (s<<std:endl);
}

void breadth_search(bool graph[MAX][MAX], int init, int goal)
{
	std :: list<int> p(1, init);
	std :: queue<std::list<int> > q;
	q.push(p);
	while(!q.empty())
	{
		p = q.front();
		q.pop();
		int v = p.back();
		if (v == goal)
			std::cout << p;
		else
			for(int i = 0; i < MAX; i++)
				if(graph[v][i] && (std::find(p.begin(), p.end(), i) == p.end()))
				{
					p. push_back(i);
					q.push(p);
					p.pop_back();
				}
		
	}

}

int main(void)
{
	bool g[MAX][MAX] = {{false, true, true, false, false},
					{false, false, false, true, false}
					{false, true, false, true, false}
					{false, false, true, false, true}
					{false, false, false, false, false}};
	breadth_search(g, 0, 4);
	return 0;
}
```
